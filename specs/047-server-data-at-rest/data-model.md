# Data Model: Данные на диске сервера

## Файлы на диске

| Путь | Что | Зашифровано |
|---|---|---|
| `<db>` | база SQLite (VFS `adiantum`, ключ данных) | все страницы |
| `<db>-wal` | журнал WAL | да |
| `<db>-shm` | индекс WAL (номера страниц и суммы, без данных) | нет, данных не содержит |
| `<db>.key` | запертый ключ данных | ключ запечатан Argon2id + XChaCha20-Poly1305 |
| `<db>-files/<id>` | готовое вложение | куски по 64 КиБ, AEAD |
| `<db>-files/<id>.part` | незаконченная загрузка | запечатанные куски |
| `<db>-files/<id>.synced` | сколько открытых байтов в `.part` лежит надёжно | число, без данных |

## `<db>.key`

```json
{"version": 1, "kdf": "argon2id", "memory_kib": 65536, "iterations": 3, "parallelism": 4,
 "salt": "<base64, 16>", "nonce": "<base64, 24>", "sealed": "<base64, 48>"}
```

## Файл вложения

| Часть | Размер |
|---|---|
| заголовок: `NOXF`, версия `1`, размер куска `65536`, резерв | 32 |
| кусок `i`: шифротекст открытых байтов `[i·64K, min((i+1)·64K, size))` + тег | ≤ 65 536 + 16 |

Ключ файла — `HKDF-SHA256(ключ данных, info = "nox/file/v1|" + file_id)`; nonce куска — `0⁴ ‖ i (8 байт BE)`; AAD — `i (8 байт BE) ‖ последний (1 байт)`.

## Бэкап (tar)

| Запись | Что |
|---|---|
| `nox.key` | копия `<db>.key` |
| `nox.db` | снимок `VACUUM INTO` (зашифрован) |
| `files/<id>` | готовые вложения как есть |
| `manifest` | JSON: имя и размер каждой записи, `created_at`, `mac` — `HMAC-SHA256(HKDF(ключ данных, "nox/backup/v1"), записи по порядку)` |

## Состояния сервера

| Состояние | Когда | Основной порт | Страница | `/health` |
|---|---|---|---|---|
| `setup` | нет ни базы, ни `<db>.key` | закрыт | пароль и повтор, предупреждение | `locked` |
| `locked` | есть оба, пароль не введён | закрыт | только поле пароля | `locked` |
| `open` | пароль введён | открыт | как сегодня + смена пароля | `ok` |
| отказ старта | есть одно без другого | — | — | — |

## База

Схема не меняется; после восстановления — новое `journal_id`.
