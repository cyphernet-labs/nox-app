# Data Model: Связь восстанавливается без перезапуска приложения

Хранимые данные не меняются: ни Sembast, ни защищённое хранилище, ни настройки. Меняется только то, что приложение держит в памяти, и состояние трёх экранов.

## Что перезапуск канала сбрасывает (в памяти)

| Где | Что | После `Try again` |
|---|---|---|
| Сокет | пауза лестницы, начатая попытка | пауза 1 с → сразу; попытка брошена, её поздний результат отброшен |
| Селектор пути | флаг неудачного круга (`roundFailed`) | снят — статус «подключаемся», плашка уходит |
| Селектор пути | сданный адрес, проверенный адрес, часы отказов ключа, последняя ошибка Tor | забыты |
| Tor-клиент | упал / поднимается дольше 90 с | остановлен, новый круг запускает заново |
| Tor-клиент | готов / спит / поднимается меньше 90 с | сохранён |

## Что не сбрасывается (на устройстве)

- адреса сервера и последний ответивший;
- ключ доступа и пометка «не зарегистрирован» (T039 фазы 040);
- вердикт сети Tor о версии клиента;
- курсор, кэш, очередь исходящих.

## Состояние экранов

Списки чатов, лента и карточка получают поле `isUnsupported` (по умолчанию `false`) рядом с `isOffline`:

| `isOffline` | `isUnsupported` | Плашка |
|---|---|---|
| `false` | — | нет (или другая плашка) |
| `true` | `false` | `No connection` + `Try again` |
| `true` | `true` | `No connection` без действия |

## Переходы статуса связи

```text
offline (No connection + Try again)
   │ Try again
   ▼
(канал перезапускается: active=false → active=true, roundFailed=false)
   ▼
connecting (угол: Connecting…, плашки нет)
   ├── приветствие сервера ──► online
   └── круг не удался ──► offline (плашка возвращается)
```
