# Quickstart: проверка восстановления связи

## Что нужно

- Сервер: `(cd client_backend && go build -o /tmp/noxd .)` или `scripts/demo-stand.sh`.
- Приложение на флейворе `stage`: `fvm flutter run --dart-define-from-file=config/stage.json -d <устройство>`.

## Автоматические проверки

```sh
make gate
make golden-verify
```

Ожидание: всё зелёное; среди тестов — зависший выбор пути брошен по пределу, перезапуск канала сохраняет только здоровый Tor, перезапуски не наслаиваются, `Try again` на плашке трёх экранов и его отсутствие у неподдерживаемого сервера.

## Сценарий 1 — `Try again` возвращает связь (US1)

1. Остановить сервер. Дождаться плашки `No connection` в списке чатов.
2. Запустить сервер.
3. Нажать `Try again`.

Ожидание: плашка сразу уходит, в углу `Connecting…`, затем связь восстанавливается без перезапуска приложения. То же — в ленте и в карточке чата, на телефоне и на Маке.

## Сценарий 2 — неудача возвращает плашку (US1)

1. При остановленном сервере нажать `Try again`.

Ожидание: на время попытки плашка уходит, затем возвращается с тем же действием. Других сообщений нет.

## Сценарий 3 — возврат на передний план (US3)

1. При плашке `No connection` свернуть приложение на телефоне, запустить сервер, вернуться в приложение.

Ожидание: попытка начинается сразу, не дожидаясь паузы.

## Сценарий 4 — зависший выбор пути (US2)

Покрыт тестом сокета: выбор пути, который не завершается, брошен через 120 с, следующая попытка началась сама.
