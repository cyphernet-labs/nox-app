## R1. Адаптивный шелл `TabBarShell` (4.1) — StatefulWidget без BLoC

- **Решение**: Новый `TabBarShell` в `lib/presentation/widgets/shell/tab_bar_shell_widget.dart` — `StatefulWidget` с локальным `AppTab _active` (enum из `app_bottom_bar_widget.dart`) + `setState`, **без BLoC**. Адаптив — `LayoutBuilder` по `Constants.railBreakpoint` (840): мобайл — `Scaffold(bottomNavigationBar: AppBottomBarWidget(active, onSelect), floatingActionButton: AppCreateFabWidget(onPressed), floatingActionButtonLocation: centerDocked)`; десктоп — `Scaffold(body: Row[AppNavigationRailWidget(leading FAB), VerticalDivider(1), Expanded(body)])`. `+` (обе раскладки) → `Navigator.push(CreateChatPage.route())` (страница сама выбирает fullscreen/Dialog). Системный back: не-Chats → `_active=chats`; Chats → `SystemNavigator.pop` (в standalone-превью заглушено `// TODO(backend):`). Повторный тап Chats → scroll-to-top (через `ScrollController`/callback к 5.1); Settings → no-op.
- **Обоснование**: Блюпринт 05 §5/§6 санкционирует BLoC-less шелл; verify подтвердил: «AppShell — StatefulWidget без BLoC, выбранная вкладка `_index` в локальном setState». M3 строит свежий `TabBarShell` на **Feature-003 kit** (`AppBottomBarWidget(active, onSelect)`, `AppCreateFabWidget(onPressed)` — подтверждённые сигнатуры) и заменяет `AppShell` как живой шелл. `tabFade`=150мс и `railBreakpoint`=840 подтверждены в токенах.
- **Reconciliation (Принцип III, тот же change-set)**: Блюпринт 05 §6.5/§6 устарел — говорит «целевое место tab-state — `AppRootBloc`» и предписывает сырые стоковые `NavigationRail`/`BottomAppBar` с `Icons.*`; живой kit — кастомный `AppBottomBarWidget` (`surfaceContainer`, `level2`, `_notchGap=72`) + SVG `NoxIcons`. §6.5/§6 правится под реальный `TabBarShell` (+ desktop list-detail) в этом же change-set.
- **Альтернативы**: `ShellBloc` (Freezed) — отклонено: tab-индекс тривиален, async/репозитория у шелла нет (карв-аут 05 §5.1); резервируется на backend-фазу. Переиспользовать `AppShell` as-is — отклонено: сырые стоковые виджеты + не смонтирован; нужен kit-композитор.

## R3. Chats list (5.1) — network-only мок-вертикаль + `ChatsListBloc` (sealed, PagingState)

- **Решение**: Открытый список чатов строится как **network-only carve-out**, зеркаля verification-only Item-слайс:

  - `GetChatsConfig` (`domain/repository/chat/`, зеркалит `GetItemsConfig`): `{page, search}`, `pageSize`/`defaultPage`, `firstPage`/`nextPage`.
  - Мок-`GetChatsApi` (`@lazySingleton`, `data/remote/api/chat/`) — синтезирует N мок-чатов + задержку + `PageMetadata`, фильтрует по `search` (как `GetItemsApi`).
  - `ChatRepository` интерфейс + `ChatRepositoryImpl` (`@LazySingleton(as: ChatRepository, env:[dev,prod,test])`) → `RepositoryResult<(List<ChatModel>, PageMetadata)>`.
  - `ChatsListBloc extends BaseBloc<ChatsListEvent, ChatsListState>` — **sealed-trio** `Initializing/Initialized/Error` (как `ItemListBloc`): `super(const ChatsListState.initializing())`; `on<Initialize>` → `Initialized(pagingState: PagingState<String, ChatModel>())` затем `loadChats(reset:true)`; `on<LoadChats>(transformer: sequential())`; `getIt<ChatRepository>()`, `executeLogic(…, onError: …)` (ОБЯЗАТЕЛЬНО `onError`), `result.match`, `PagingStateExt.applyPage(keyExtractor: (c)=>c.id)`, re-check `state is Initialized` после `await`. `Initialized` несёт доп. поля: `query: String`, `isOffline: bool`, `selectedChatId: String?` (десктоп).
  - Рендер: `PagedListView<String, ChatModel>.separated` (item = `AppChatItemWidget`), `noItemsFoundIndicatorBuilder` → `AppEmptyContentWidget(illustration: Assets.svg.illustrations.emptyChats, …)`; `Initializing`→`AppProgressWidget`; `Error`→`AppErrorWidget(onTryAgain:)`. - **Обоснование**: Блюпринт 00/05 прямо называет открытый список чатов **первой реальной network-only фичей** (verify MAJOR: inline in-memory список нарушил бы инвариант). `ItemListBloc` (`item_list_bloc.dart:23-88`), `PagingStateExt.applyPage` (`paging_state_ext.dart:6-22`), `GetItemsConfig`/`GetItemsApi`/`ItemRepositoryImpl` — проверенные шаблоны. `AppChatItemWidget(name, preview, time, unread, onTap)` — `time` **предформатированная строка** (форматирует вызывающий, R6). `AppEmptyContentWidget`/`Assets.svg.illustrations.emptyChats` подтверждены.
- **Поиск**: `query` идёт в `GetChatsConfig.search` (серверный контракт, как `GetItemsConfig.search`); мок-API фильтрует. В UI-фазе real-time фильтрация — re-fetch по debounced `searchChanged` (`debounceRestartable()`); реальный серверный поиск — `// TODO(backend):`. `AppSearchBarWidget` — **display-only** (verify), поэтому вводится `AppSearchFieldWidget` (R7).
- **Альтернативы**: inline in-memory список в bloc — отклонено (нарушает network-only инвариант). value-state вместо sealed — отклонено: пагинированный список ⇒ sealed-trio + `PagingState` (как `ItemListBloc`). `infinite_scroll_pagination` v5 — первый реальный потребитель (блюпринт 07).
