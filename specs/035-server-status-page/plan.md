# Implementation Plan: Стартовая и статусная страница сервера

**Branch**: `035-server-status-page` | **Date**: 2026-09-07 | **Spec**: [spec.md](./spec.md)

## Summary

Страница живёт на **собственном слушателе loopback** — не путём на основном мультиплексоре. Это и есть вся защита: проверку адреса внутри обработчика однажды обойдут заголовком, а сокета, которого нет в сети, не обойти ничем. Пустое значение `-status-addr` выключает слушатель целиком.

Одна страница, два состояния, и решает между ними **тот же предикат**, что решает про claim-ссылку в выводе запуска: «владелец ещё может войти». Второго определения «забран» не заводится — фаза 033 ровно это и вычёркивала.

Ссылка на странице — **та же самая**, что напечатана при запуске. Минтить новый claim-токен на каждую загрузку страницы значило бы плодить бессрочные двери на каждое обновление браузера.

Статус собирается одним чтением: версия из бинарника, аптайм от старта процесса, счётчики и размер файла базы. Ни одного имени, названия, ключа и токена — Принцип I, и для страницы он строже, чем для логов.

## Technical Context

**Language/Version**: Go 1.27, только `client_backend/`. Клиент не затрагивается вовсе.

**Primary Dependencies**: три прямые + **одна новая**: чисто-Go кодировщик QR без собственных зависимостей. Обоснование — [research.md](./research.md) Р2; правило `client_backend/CLAUDE.md` требует письменного, и оно там же.

**Storage**: схема **не меняется**. Читаются существующие таблицы; размер базы — размер файла на диске.

**Testing**: `go test -race ./...`. HTTP через `httptest` против настоящего мультиплексора страницы.

**Target Platform**: один процесс на машине владельца.

**Project Type**: только сервер. Ни одной правки в `lib/`, ни одного нового голдена.

**Performance Goals**: не применимо. Страницу открывают руками; счётчики — четыре `COUNT(1)` по таблицам круга ~10 человек.

**Constraints**: страница недостижима по сети (FR-001); `/health` не меняется (FR-013); вывод запуска сохраняется (FR-014); ни одного имени на экране (FR-011).

**Scale/Scope**: одна новая директория обработчиков, один слушатель, один флаг, ноль миграций.

## Constitution Check

| Принцип | Как соблюдается | Вердикт |
|---|---|---|
| **I. Приватность и E2EE** | Страница показывает только счётчики и свойства машины. Ни имён, ни названий чатов, ни текстов, ни ключей устройств, ни токенов — и это проверяется тестом против сервера, у которого всё это есть. | ✅ |
| **II. Спецификации — источник истины** | Спека и решения `/speckit-clarify` записаны до кода; `roadmap-stage2.md`, `client_backend/CLAUDE.md` и заметка о машине без экрана правятся в этом же change-set'е. | ✅ |
| **III. Блюпринт обязателен** | Клиента не касается. Серверная часть следует `ws-rest-patterns` и `go-style`. | ✅ |
| **IV. Верность дизайн-системе** | Не применяется: это служебная страница на машине оператора, а не поверхность продукта. Дизайн-корпус её не описывает и описывать не должен. | ✅ |
| **V. Языковая дисциплина** | Спека и доки русские; код, коммиты, ветка английские. Текст самой страницы — **английский**, как весь UI. | ✅ |
| **VI. Паритет mobile ↔ desktop** | Не применяется: у страницы нет мобильной и десктопной версии, она одна и открывается на машине сервера. | ✅ |
| **VII. Контракт провода — закон** | Провод не меняется. Страница — не API: её формат ничем не зафиксирован, машинный ответ остаётся за `/health`, и это записано в контракт §1 отдельной строкой, чтобы никто не начал парсить HTML. | ✅ |

**Нарушений нет.**

Отдельно про **инвариант 1** (ровно один процесс открывает базу): второй слушатель — это второй сокет в том же процессе, а не второй процесс. И про **инвариант 9** (порядок остановки): слушатель страницы гасится вместе с основным, до закрытия базы, иначе запрос в момент остановки прочитает закрывающееся хранилище.

## Порядок работ

1. **Конфигурация** — флаг, значение по умолчанию, отказ на не-loopback адресе.
2. **Данные** — счётчики в store, состояние машины в `status.go`, версия из бинарника.
3. **Слушатель** — второй HTTP-сервер, поднимается и гасится вместе с основным; claim-ссылка кэшируется одна на процесс.
4. **Страница** — две ветки разметки, QR, автообновление только в состоянии «забран».
5. **Тесты** — недостижимость по сети, обе ветки, приватность, `/health` без изменений.
6. **Доки** — контракт, роадмап, CLAUDE.md, случай машины без экрана.
