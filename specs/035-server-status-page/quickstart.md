# Quickstart: проверка фазы 035

## Гейты

```bash
cd client_backend && gofmt -l . && go vet ./... && go test -race ./...
```

Клиента фаза не касается: `make gate` и `make golden-verify` должны остаться ровно теми же числами, что до неё.

## Сценарий 1 — забрать сервер, не перепечатывая ссылку (US1, SC-001)

1. Свежая база, `./noxd`. В выводе запуска — claim-ссылка **и** адрес страницы.
2. Открыть `http://127.0.0.1:8081` в браузере на той же машине.
3. Крупный QR, та же ссылка текстом, короткое объяснение.
4. Снять QR телефоном **с экрана**, предъявить в приложении.

**Ожидается**: сервер забран, ни одного перепечатанного символа. Ссылка на странице совпадает с напечатанной в выводе.

## Сценарий 2 — по сети недостижимо (SC-002)

С другого устройства в той же сети:

```bash
curl --max-time 3 http://<адрес машины>:8081/
```

**Ожидается**: соединение не устанавливается. Не 403, не 404 — «connection refused» или таймаут.

## Сценарий 3 — состояние машины (US2, SC-004)

Обновить страницу после захвата.

**Ожидается**: ссылки нет; видны версия и билд, аптайм, версия схемы, «забран», идентификатор хранилища, счётчики людей/устройств/чатов/сообщений, размер базы. Страница обновляется сама раз в 10 секунд — аптайм растёт без нажатий.

## Сценарий 4 — ссылка возвращается (граничный случай)

Отозвать последнее устройство владельца (выход из приложения), обновить страницу.

**Ожидается**: ссылка и QR снова на месте. «Забран» для страницы значит то же, что для сервера: **владелец ещё может войти**.

## Сценарий 5 — приватность (US3, SC-005)

На сервере есть люди, чаты и переписка.

```bash
curl -s http://127.0.0.1:8081/ | grep -iE "<имя человека>|<название чата>|<кусок сообщения>"
```

**Ожидается**: ни одного совпадения. Проверить заодно, что в разметке нет публичных ключей устройств и claim-токена.

## Сценарий 6 — выключение и отказ на не-loopback

```bash
./noxd -status-addr ""            # страницы нет, порт не занят
./noxd -status-addr 0.0.0.0:8081  # отказ при запуске с внятной причиной
```

## Сценарий 7 — `/health` не тронут (SC-006)

```bash
curl -s http://127.0.0.1:8080/health
```

**Ожидается**: `{"status":"ok"}`, как и было.
