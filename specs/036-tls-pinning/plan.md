# Implementation Plan: TLS с пиннингом по отпечатку ключа сервера

**Branch**: `036-tls-pinning` | **Date**: 2026-09-07, переработан 2026-09-14 | **Spec**: [spec.md](./spec.md) · [research.md](./research.md)

## Summary

Сервер выпускает себе сертификат **из ключа своей личности** — того самого, что лежит в `server_identity` с фазы 032 и чей отпечаток едет в каждой ссылке спаривания. Клиент отключает проверку цепочки и ставит на её место одно сравнение: отпечаток ключа предъявленного сертификата равен сохранённому при спаривании. Термины разведены в спеке: **ключ** — пара в `server_identity`, **отпечаток** — тридцать два байта в ссылке, **пиннинг** — сама сверка.

Ключ при этом **переводится с Ed25519 на ECDSA P-256** — не по вкусу, а потому что спайк 2026-09-14 показал: Ed25519-сертификат Dart не принимает вовсе, рукопожатие рвётся до колбэка, и чинить это на клиенте нечем ([research.md](./research.md), решение 1). Смена бесплатна: ключ используется только для сборки ссылки, им никто ничего не подписывает и не проверяет.

Из этого следует остальное. В ссылке остаются те же тридцать два байта, но теперь это отпечаток, а не ключ, — и поле переименовывается, чтобы не врать именем. Сертификат собирается при каждом запуске в памяти и нигде не хранится: доверие на ключе, сертификат — расходник. Клиент достаёт ключ из сертификата поиском фиксированного заголовка, без разбора ASN.1 и без новых зависимостей.

Служебная страница фазы 035 остаётся открытым HTTP на loopback: сетевого трафика у неё нет по построению.

## Technical Context

**Language/Version**: Go 1.27 (сервер) + Dart / Flutter 3.44.1 FVM (приложение).

**Primary Dependencies**: ни одной новой. На сервере — `crypto/tls`, `crypto/x509`, `crypto/ecdsa` из стандартной библиотеки; на клиенте — `HttpClient` из `dart:io`, который `IOWebSocketChannel` и Dio используют под собой, и `package:crypto`, который в проекте уже есть.

**Storage**: таблица та же, **содержимое колонок меняется** — `server_identity.private_key` становится PKCS#8, `public_key` становится SPKI. Миграции нет: правило одной миграции до первого релиза, и `001_init.sql` тут не трогается вовсе, потому что типы колонок не меняются.

**Testing**: `go test -race ./...` с настоящим TLS через `httptest.NewUnstartedServer` + **собственный** `tls.Config` (не `NewTLSServer`: он ставит стоковый сертификат, и главная проверка фазы стала бы пустой); на клиенте — чистая функция сверки против подставных сертификатов; живой прогон по [quickstart.md](./quickstart.md) с перехватом трафика.

**Target Platform**: сервер — процесс на машине владельца; приложение — iOS, Android, macOS, Windows, Linux.

**Project Type**: клиент-серверная пара; меняется транспорт с обеих сторон, одна строка контракта и значение одного поля ссылки.

**Performance Goals**: не применимо. Рукопожатие один раз на соединение, соединение живёт часами.

**Constraints**: провод (команды, события, коды) **не меняется вовсе**; развёрнутых установок нет, поэтому переходных режимов и миграций не требуется; отката на открытый канал нет.

**Scale/Scope**: один человек и его устройства. Затрагивается один слушатель на сервере, фабрика сокета и HTTP-клиент на клиенте, один манифест Android.

**Structure Decision**: один новый файл на сервере и один на клиенте. Транспорт открывается в двух местах — фабрика сокета и адаптер Dio, — и оба получают **один и тот же** `HttpClient`: `WebSocket.connect` переданный клиент не закрывает, поэтому клиент на каждое подключение означал бы течь на каждой переподключке.

## Порядок работ

1. **Контракт** — схема адреса и значение тридцати двух байт.
2. **Сервер** — ключ на ECDSA, сертификат из него, `tls.Config`, `ServeTLS`; страница 035 не трогается.
3. **Клиент** — чистая сверка, один `HttpClient` в оба транспорта, `wss`/`https`, снятие запасного адреса.
4. **Отказ** — терминальная фаза, остановка лестницы, две строки, плашка на трёх экранах и на входе.
5. **Android** — снять разрешение на открытый трафик.
6. **Тесты** — подменённый сервер отвергается; перевыпущенный на том же ключе принимается; отказ ничего не стирает; байты файлов едут по тому же каналу.
7. **Стенд и живой прогон** — перехват трафика и намеренно неверный отпечаток.
8. **Доки** — контракт, роадмап, CLAUDE.md.
