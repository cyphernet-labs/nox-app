# Контракт: ссылка спаривания версии 3

```
nox://pair/<base64url без '='>
```

## Байты

| Поле | Размер | Значение |
|---|---|---|
| Версия | 1 | `0x03` |
| Ключ сервера | 32 | открытый ключ Ed25519 |
| Токен | 16 | одноразовый токен спаривания |
| Адреса | ≥ 1 адреса | список до конца ссылки |

Адрес: `тип` (1 байт) ‖ `длина значения` (1 байт) ‖ `значение`.

| Тип | Имя | Значение | Длина |
|---|---|---|---|
| `1` | IPv4 | 4 байта адреса ‖ порт (2 байта, big-endian) | 6 |
| `2` | IPv6 | 16 байт адреса ‖ порт | 18 |
| `3` | имя | имя UTF-8 (1–253 байта) ‖ порт | длина имени + 2 |
| `4` | onion | открытый ключ onion-сервиса (32); адрес `…onion` вычисляется из него, порт — 443 | 32 |

## Разбор

1. Префикс не `nox://pair/` или base64url не читается — **испорченная**.
2. Меньше 49 байт — **испорченная**.
3. Версия больше 3 — **«обновите приложение»**; иная, кроме 3 — **испорченная**.
4. Адреса: неполный заголовок, длина за концом, известный тип с неверной длиной, порт 0, имя пустое или не UTF-8 — **испорченная**; неизвестный тип пропускается по длине.
5. Ни одного известного адреса — **испорченная**.

Порядок адресов сохраняется: приложение пробует сначала прямые, потом onion.

## Выпуск

Сервер выпускает только версию 3 — и claim, и приглашения: один прямой адрес (адрес, на котором слушает, как сегодня) и onion, если сервис опубликован. Публичный адрес добавляет 045.

До 045 по onion-адресу из ссылки нельзя спариться: onion-сервис открывается только ключом доступа спаренного устройства. Приложение спаривается по прямым адресам, а onion-адрес сохраняет для связи после спаривания.

## Что приложение сохраняет

- ключ сервера — `session.server_key`;
- первый прямой адрес — `session.server_address` (адрес, с которого начинается связь);
- все прямые адреса по порядку — список `direct` в `session.server_addresses`, onion-адрес — поле `onion` там же.

Векторы — `link-vectors.json`.
