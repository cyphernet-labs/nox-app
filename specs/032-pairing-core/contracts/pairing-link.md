# Контракт: ссылка спаривания

**Фаза 1** для [plan.md](../plan.md) · 2026-09-04

Один формат на все кейсы — один разбор, один сканер, один набор тестов. Из четырёх типов токена модели в этой фазе выпускаются два (`claim`, `invite-device`), но **формат от типа не зависит и знать его не может**: тип живёт на сервере.

## Внешняя форма

```
https://nox.app/p/#<base64url без padding>
```

Полезная нагрузка — во **фрагменте**. Фрагмент браузер на сервер не отправляет, поэтому ссылка, случайно открытая в браузере, токен никуда не сливает. Приложение читает ссылку сканом QR или вставкой текста; открытие по клику из браузера в этой фазе **не обещается** (глубокие ссылки — отдельная фаза).

Разбор ДОЛЖЕН принимать ссылку и без схемы — человек может вставить только фрагмент.

## Байтовая раскладка

| Смещение | Поле | Размер | Значение |
|---|---|---|---|
| 0 | `version` | 1 | `0x01` для этого формата |
| 1 | `host_type` | 1 | `0x01` IPv4 · `0x02` IPv6 · `0x03` DNS-имя |
| 2 | `host` | 4 / 16 / 1+N | по типу; для DNS — байт длины, затем имя в UTF-8 |
| … | `port` | 2 | big-endian |
| … | `server_key` | 32 | публичный ключ сервера, Ed25519 |
| … | `token` | 16 | значение токена |

Итог: 56 байт для IPv4 → **75 знаков** base64url. QR невысокой плотности, уверенно снимается с экрана.

(Модель считала ~55 байт, потому что не закладывала отдельный байт типа адреса; с ним — 56.)

**Тип адреса записан явно, а не выводится разбором.** Модель говорит «определяется разбором», но `1.2.3.4` читается и как IPv4, и как имя хоста; один байт снимает неоднозначность навсегда и стоит меньше, чем спор двух реализаций о том, что такое адрес.

## Правила разбора

1. Неизвестная `version` — **отказ с отдельной причиной**, а не попытка угадать раскладку.
2. Длина, не сходящаяся с раскладкой, — отказ до всякой попытки соединиться.
3. Отказ разбора обязан быть **отличим** от отказа токена: «ссылка не читается» и «токен недействителен» — разные сообщения, потому что действия у человека разные.
4. `server_key` в этой фазе **разбирается и хранится, но ни с чем не сверяется** — сверять не с чем, пока транспорт не TLS. Носится сейчас, чтобы приход пиннинга не менял формат.

## Контрольный вектор

Закрепляется как `login_ref` в §3 — чтобы совпадение двух реализаций было свойством провода, а не удачей.

```
host      = 127.0.0.1, port = 8080
server_key = A6EHv/POEL4dcN0Y50vAmWfk1jCbpQ1fHdyGZBJVMbg=
token      = 0x00…0x0f (16 байт)
```

Точная base64url-строка фиксируется тестом обеих сторон при реализации.
