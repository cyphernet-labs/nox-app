## Предусловие: снести старую базу

Схема правилась на месте. Старый файл несовместим, и первый же запуск на нём упадёт.

```
rm -rf /tmp/nox-demo
```

## 1. Поднять чистый сервер

```
./scripts/demo-stand.sh --reset-app
```

Ожидается: в логе старта две ссылки — claim для человека у терминала и адрес страницы статуса на петле.

**Проверить**: страница статуса открывается, показывает состояние «сервер свободен», и на ней **нет счётчика людей**.

## 2. Забрать сервер

Открыть приложение на первом устройстве, пройти по claim-ссылке.

**Проверить**:
- вход завершается **сразу** — экрана ожидания чужого решения не появляется;
- в настройках есть `Devices` и **нет** `People`;
- в карточке личности **нет** отметки `Server owner`;
- страница статуса переключилась в состояние «забран».

## 3. Подключить второе устройство

Настройки → `Devices` → показать QR → отсканировать со второго устройства.

**Проверить**: устройство входит, оба видят друг друга в списке, отзыв работает.

## 4. Переписка между своими устройствами

Создать чат, отправить текст, файл и картинку с первого устройства.

**Проверить**:
- на втором устройстве всё пришло, сообщения показаны **своими**;
- картинка отдаёт превью в ленте, файл скачивается;
- выключить второе устройство, написать с первого, включить обратно — пропущенное догоняется реплеем.

## 5. Шов приглашения

**В шапке чата** — действие приглашения, неактивное.

**В карточке чата** — секция `People`, в ней одна строка (сам человек), под ней выключенная кнопка `Invite a person` с подписью `Available in a future version`.

**Проверить**:
- нажатие не делает **ничего** — ни экрана, ни ошибки, ни снэкбара;
- на узком и на широком окне кнопка на месте и вёрстка не поехала;
- чтение с экрана называет действие и объявляет его недоступным.

**Отдельно (SC-005)**: показать экран человеку, который видит приложение впервые, и спросить, что он думает про эту кнопку. Ответ «появится позже» — успех; ответ «сломано» — провал формулировки, и подпись надо менять.

## 6. Мёртвые команды

Убедиться, что старая команда получает отказ «неизвестная команда», а не пустой успех. Проверяется тестом уровня протокола; руками — не обязательно.

## 7. Гейты

```
make gate
make golden-verify
cd client_backend && go test -race ./...
```

Все три зелёные. Число тестов уменьшилось ровно на удалённые; ни один оставшийся не падает.
