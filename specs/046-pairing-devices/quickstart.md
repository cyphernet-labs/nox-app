# Quickstart: спаривание и устройства

## 1. Автоматические проверки

```bash
cd client_backend && gofmt -l . && go vet ./... && go test -race ./...   # токены, запросы, события, noxd link
make gate && make golden-verify                                          # ожидание, диалог, исходы, обе ширины
```

## 2. Сквозной прогон на macOS

```bash
cd client_backend && go build -o "$STAND/noxd" . && "$STAND/noxd" -db "$STAND/nox.db" -addr 0.0.0.0:8443 -status-addr 127.0.0.1:8081

# Сервер стартует запертым (047): до пароля слушает только служебная страница, и ссылки на ней нет.
# Пароль — на странице или из другого терминала; новый сервер принимает его дважды
"$STAND/noxd" unlock -status-addr 127.0.0.1:8081
```

1. Когда пароль введён, страница `http://127.0.0.1:8081` сразу показывает QR-код, ссылку и `Expires in 10 minutes`; в журнале сервера ссылки нет.
2. `noxd link` печатает новую ссылку; ссылка на странице перестала работать.
3. Приложение спаривается по ссылке с машины → выбор имени → чаты.
4. В «Устройствах» `Add a device` → QR-код. Второе устройство (второй экземпляр приложения) предъявляет токен → ждёт; в приложении — диалог `New device: …`; `Allow` → второе устройство спарено, список обновился. Повтор с `Deny` → отказ, токен сгорел. Повтор с `Cancel` на новом устройстве → запрос отозван, диалог закрылся. Повтор без ответа 10 минут → срок.
5. Выйти из приложения с единственного устройства → страница снова показывает ссылку сразу; новое спаривание по ней видит прежнюю переписку.

Без интерфейса тот же путь проходят:

```bash
cd client_backend && go run ./cmd/smoke "$("$STAND/noxd" link -status-addr 127.0.0.1:8081 | head -1)"   # провод: ссылка с машины, Allow, Deny, Cancel
fvm flutter test test/live/pairing_live_probe.dart --dart-define=status=127.0.0.1:8081            # код приложения с обеих сторон
fvm flutter test test/live/pairing_live_probe.dart --dart-define=status=127.0.0.1:8081 --dart-define=expiry=true --plain-name 'nobody answers'   # срок без ответа, 10 минут
```
