# Контракт: ссылка с машины на служебной странице и `noxd link`

Служебная страница — loopback, открытый HTTP, вне контракта v0. Здесь — правила записи.

## Состояния страницы

| Состояние | Что видно |
|---|---|
| Устройств нет, ссылка живая | QR-код, ссылка, `Expires in 10 minutes` (обратный отсчёт в минутах), `Copy` |
| Устройств нет, ссылка истекла | `Link expired`, кнопка `New link` |
| Устройства есть, ссылки нет | `Add a device` |
| Устройства есть, ссылка живая | как первая строка |
| Устройства есть, ссылка истекла | `Link expired`, `New link` |

При первом открытии страницы сервера без устройств ссылка выпускается сама — только если нет ни одной непредъявленной ссылки с машины, живой или истёкшей; дальше — только кнопками. Ссылка хранится в базе и переживает перезапуск сервера.

## Кнопки страницы

`POST /link` (`application/x-www-form-urlencoded`, поле `token`): проверки `Host`, `Origin = http://<Host>`, токен формы (как `Set` в 045). Успех — новая ссылка (прежняя гаснет), `303` на `/`.

## `noxd link`

```
noxd link [-status-addr 127.0.0.1:8081]
```

`POST /control/link` на служебный адрес:

- заголовок `X-Nox-Control: 1` обязателен, `Origin` — запрещён, `Host` — локальный; иначе `403`;
- ответ `200`, `{"link": "nox://pair/…", "expires_at": 1790000600}`;
- команда печатает ссылку и `Expires in 10 minutes` в stdout; прежняя живая ссылка гаснет.

Ни страница, ни команда не пишут ссылку и токен в журнал сервера.
