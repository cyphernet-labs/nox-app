# Data Model: Спаривание и устройства

## Сервер (`001_init.sql` правится на месте)

### `server_identity`

`owner_user_id` и `claimed_at` уходят. Остаются ключ сервера и (045) адреса.

### `pair_tokens`

| Колонка | Стало |
|---|---|
| `kind` | `'machine'` (ссылка с машины) или `'invite_device'` |
| `issuer_key` | ключ устройства, выпустившего приглашение (`NULL` у ссылки с машины) |
| `expires_at` | обязателен: создание + 10 минут у обоих видов |
| `used_at`, `used_by`, `paired_user_id`, `created_person` | без изменений: исход записывается в момент траты токена |

- Живая ссылка с машины одна: выпуск новой гасит (`used_at`) непредъявленные прежние.
- Ни одно значение токена не пишется в журнал.

### `pair_requests` (новая)

| Колонка | Что |
|---|---|
| `request_id` | `r_` + 16 hex |
| `token` | токен приглашения (уникален: один запрос на приглашение) |
| `device_key` | ключ нового устройства из канала |
| `platform` | `ios`/`android`/`macos`/`windows`/`linux` |
| `issuer_key` | ключ выдавшего устройства |
| `expires_at` | срок приглашения |
| `outcome` | `NULL` (ждёт) / `allowed` / `denied` / `expired` / `cancelled` |
| `decided_at` | когда закрыт |

Переходы: ждёт → `allowed` (`device.approve allow`) / `denied` (`device.approve deny`, выдавший отозван) / `expired` (срок) / `cancelled` (`pair.cancel`). Закрытый запрос не меняется; токен сгорает при любом исходе.

### `devices`

`last_seen_at` — при каждом приветствии (как сегодня). `platform`, `created_at` — без изменений.

### В памяти процесса

Живая ссылка с машины (токен и срок) для служебной страницы; таймер сроков запросов.

## Приложение

### Новое устройство

Состояние спаривания: `connecting` → `waiting(expiresAt)` → `paired` | `declined` | `expired` | `cancelled`. Ключ устройства и токен — те же при повторе в пределах срока (FR-011); выход и `Cancel` возвращают к экрану спаривания.

### Выдавшее устройство

`PairRequest {requestId, platform, expiresAt}` — живые запросы, адресованные этому устройству; приходят событием и после каждого приветствия; уходят по `device.pairResolved` или сроку. Не хранятся на диске.

### Убирается

`LoginStatus.errorHomeNetworkOnly`, `errorServerMismatch` (причины — экран подключения 045); onion-приглашения на 7.8.
