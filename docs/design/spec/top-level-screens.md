# Карта верхнеуровневых экранов

> Черновик 2026-05-28, обновлён после закрытия всех верхнеуровневых открытых вопросов и ревью 2026-05-29. Названия экранов — рабочие; точные формулировки лейблов в UI определяются в детальных спеках `screens/`.

## Соответствие со структурой Signal

Signal использует нижние табы **Chats / Calls / Stories** + настройки через аватар. В NOX табов меньше, центральный элемент панели — кнопка действия, а не таб, и список чатов глобальный.

| Signal | NOX | Комментарий |
|---|---|---|
| Splash + onboarding по номеру + SMS | Splash + анонимное спаривание по ссылке / QR + установка имени | Разделы 1 и 2 |
| Tab Chats | Tab 1 «Chats» (глобальный список) | В NOX все чаты видны всем |
| «New chat» (карандаш) | Центральная «+» | Создание нового чата, открыто всем |
| Tab Calls | — | Вне scope |
| Tab Stories | — | Вне scope |
| Settings через аватар | Tab «Settings» | Профиля как отдельного экрана нет |

## Карта экранов NOX

### 1. Запуск

| ID | Экран | Назначение |
|---|---|---|
| 1.1 | **Splash** | Логотип (brand-fixed тёмный фон); проверка состояния авторизации. Если устройство спарено — переход в 4.1 (авто-вход); иначе — в 2.1. |

### 2. Онбординг

| ID | Экран | Назначение |
|---|---|---|
| 2.1 | **Предъявление ссылки спаривания** | Поле для вставки ссылки, которую напечатал сервер (claim) или выпустило другое устройство (приглашение); переключение в режим QR (2.2). |
| 2.2 | **Сканирование QR** | Камера-сканер той же ссылки; переключение обратно на ручную вставку (2.1). |
| 2.3 | **Установка имени пользователя** | Показывается только когда спаривание **завело личность** (claim своего сервера); приглашённому устройству имя уже принадлежит, и выбора быть не должно. Сервер уже назначил `User<random>`; экран опционально позволяет изменить имя (лимит 32, проверка символов и длины — **имена не уникальны и на занятость не проверяются**), кнопка «Готово». В дальнейшем редактируется в 7.1. |

Поток первого входа: `1.1 → (2.1 ↔ 2.2) → 2.3 → 4.1`; при спаривании по приглашению — `1.1 → (2.1 ↔ 2.2) → 4.1`, минуя 2.3.

⚠️ **Смена смысла (фаза 032).** Раньше 2.1 принимал сам идентификатор входа — предъявление секрета делало предъявителя его владельцем. Теперь предъявляется **одноразовая ссылка спаривания**, а устройство заводит собственную пару ключей и доказывает владение подписью; идентификатор входа с провода ушёл.
Поток повторного запуска: `1.1 → 4.1` (авто-вход).
Ошибки входа: формат / сеть — **inline** на 2.1; fatal / server-5xx — экран 3.1 со стрелкой back.

### 3. Универсальный экран ошибки

| ID | Экран | Назначение |
|---|---|---|
| 3.1 | **Ошибка** | Параметризован: иконка, заголовок/сообщение, кнопка `Try again`. Два режима: **блокирующий** (без back, последний в стеке — системный back сворачивает приложение) и **встраиваемый** (со стрелкой back). Используется только для fatal / неожиданных ошибок. |

### 4. Основной шелл

| ID | Экран | Назначение |
|---|---|---|
| 4.1 | **Tab bar shell** | Каркас приложения: нижняя панель из трёх элементов — таб «Chats» (5.x), центральная docked-«+» (6.1, видна на обоих табах), таб «Settings» (7.x). Полная спецификация — [screens/tab-bar-shell.md](screens/tab-bar-shell.md). |

Центральный элемент панели — кнопка действия, не самостоятельный таб с собственным состоянием.

### 5. Tab «Chats»

**Модель:** глобальное открытое пространство. Все чаты видны всем; пишет любой; «присоединения» нет; **удаления нет** ни на каком уровне.

| ID | Экран | Назначение |
|---|---|---|
| 5.1 | **Список чатов** | Глобальный список всех чатов с превью последнего сообщения, относительным временем, бейджем непрочитанных (от последнего открытия, cap `99+`). В хедере — **поисковая строка по имени чата**. Точки входа: чат (5.2), создание (6.1, из центра нижней панели). |
| 5.2 | **Лента чата** | Список сообщений (текст + файлы-chip). Каждое сообщение подписано label автора; статус своих — только `sent`. Композер внизу: поле ввода, кнопка вложения, кнопка отправки. Хедер: имя чата, переход в карточку (5.4). |
| 5.3 | **Просмотр файла** | Иконка типа + имя + размер; auto-download в кэш, сохранение в Downloads. Превью содержимого нет. |
| 5.4 | **Карточка чата** | Имя чата, список вложений (List/Grid). Описания, действий «Удалить», раздела «участники / роли» нет. |

### 6. Создание чата (центральная «+»)

| ID | Экран | Назначение |
|---|---|---|
| 6.1 | **Создание чата** | Полноэкранная форма: поле «Имя чата» (лимит 64, **валидация уникальности в реальном времени** — занятое имя выбрать нельзя), кнопка «Создать». Открыто любому пользователю. После создания — сразу в 5.2 нового чата. |

«Присоединение к чату» как отдельный поток отсутствует.

### 7. Tab «Settings»

Отдельного экрана профиля нет; всё, что обычно относится к профилю, размещено здесь.

| ID | Экран | Назначение |
|---|---|---|
| 7.1 | **Корень настроек** | Карточка идентичности (имя пользователя + `Your ID`), затем плоский список: Notifications, Appearance, Language, Terms, About, Log out. |
| 7.2 | **Уведомления** | Один переключатель push (on/off); push только по «своим» чатам. |
| 7.3 | **Внешний вид** | Тема: System / Light / Dark. |
| 7.4 | **Язык** | System / English / Українська. |
| 7.5 | ~~**Поддержка**~~ | **Вне scope текущей версии.** |
| 7.6 | **Terms** | Юридическая информация (bundled), футер — версия приложения. |
| 7.7 | **О приложении** | Только версия + build. |
| 7.8 | **Устройства** | Список устройств личности (семейство ОС, когда привязано, когда было на связи), отзыв любого из них и выпуск приглашения для нового — QR и ссылка, живут 10 минут. Отзыв **своего** устройства — это выход из аккаунта, и говорит он копирайтом выхода. |

Пункт «Logout» в корне (7.1) — действие с диалогом подтверждения, без отдельного экрана. **Полностью очищает идентификатор и локальные данные с устройства**; в диалоге подтверждения это явно проговорено в копирайте. С фазы 032 выход вдобавок **отзывает собственный ключ на сервере**, если связь есть: иначе ключ остался бы дверью, о которой никто не помнит.

#### Блок имени пользователя в корне настроек (внутри 7.1)

- Показ текущего label; inline-редактирование с проверкой символов и длины (лимит 32 символа). **Уникальность не проверяется** — имена людей не уникальны (решение владельца 2026-09-02), поэтому нет ни спиннера проверки, ни отказа «занято».

#### Блок идентификатора в корне настроек (внутри 7.1)

- Показ `Your ID`; по умолчанию **полностью замаскирован** (8 точек фиксированной длины `••••••••`).
- Кнопка `Show` раскрывает целиком. Действия: `Copy`, `Show QR`.
- ⚠️ **Фаза 032:** `Your ID` — публичный идентификатор личности, выданный сервером, а не секрет входа. `Show QR` больше не показывает QR идентичности (это раздавало бы предъявительский секрет) и ведёт на **7.8**, где приглашение выпускается настоящим одноразовым токеном.

## Глобальная навигация — решение

Принято: **нижняя панель из трёх элементов** — Chats / «+» (docked FAB) / Settings. Альтернатива «без нижней панели» отклонена. Поведение панели — в [4.1](screens/tab-bar-shell.md).

## Принятые решения

Полная таблица — в [overview.md](overview.md#принятые-решения). Ключевое на уровне карты:

- Авто-вход; идентификатор хранится локально; имя (`User<random>`) есть всегда.
- Одна идентичность на устройство.
- Термины UI: «чат», `Your ID`, `Sign in` / `Log out`.
- Splash — brand-fixed тёмный (исключение из темизации).
- Центральная «+» — docked FAB, видна на обоих табах.
- Маска идентификатора — 8 точек фиксированной длины.
- Logout — полная очистка.
- Label и имя чата уникальны глобально (лимиты 32 / 64).
- Удаление чата невозможно.
- Статус сообщений — только `sent`; непрочитанные — от последнего открытия (`99+`); push — только по «своим» чатам.
- В списке чатов — поисковая строка по имени.

## Открытые вопросы

На уровне верхнеуровневой карты экранов открытых вопросов нет. Оставшееся — артефакты дизайн-системы (палитра, типографика, токены, логотип, иллюстрации empty-states), готовятся отдельным блоком перед макетами.
