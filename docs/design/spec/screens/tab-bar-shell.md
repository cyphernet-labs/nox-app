# 4.1 Tab bar shell

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 4.1 закрыты 2026-05-29.

## Назначение

Каркас авторизованной части приложения. Содержит нижнюю панель навигации и область контента, в которой рендерятся root-экраны табов. Это единственный кастомный навигационный элемент NOX (не сводится к стандартному `NavigationBar` — см. [overview.md / Дизайн-фреймворк](../overview.md#дизайн-фреймворк)).

Шелл — точка назначения всех пост-логин маршрутов (`1.1 → 4.1`, `2.4 → 4.1`, `2.3 → 4.1`) и контейнер, поверх которого pushed-экраны (5.2, 5.3, 5.4, 6.1, 7.2–7.4, 7.6–7.8, 7.10) открываются на весь экран **без нижней панели**.

## Контекст и переходы

- **Откуда:** 1.1 Splash (авто-вход), 2.4 (спаривание к существующему человеку) или 2.3 (после онбординга).
- **Внутри (табы, без анимации стека):**
  - таб **Chats** → root-экран 5.1;
  - таб **Settings** → root-экран 7.1.
- **Действие (центральная «+»):** открывает 6.1 (push поверх шелла).
- **Pushed поверх шелла (на весь экран, панель скрыта):** 5.2, 5.3, 5.4 (из Chats-стека), 7.2–7.4, 7.6–7.8, 7.10 (из Settings-стека), 6.1.

## Лейаут

Material `Scaffold` с кастомной нижней панелью; адаптируется под тему через `ColorScheme`.

- **Body:** активный root-экран таба. Состояние каждого таба **сохраняется** при переключении: обе вкладки смонтированы в одном `Stack`, скрытая — под `IgnorePointer` и с нулевой прозрачностью (`AnimatedOpacity`, смена — `tabFade`), поэтому скролл-позиция и ввод не сбрасываются.
- **Нижняя панель — `BottomAppBar` с центральным вырезом (notch) + docked `FloatingActionButton`:**

```
┌───────────────────────────────┐
│            ╭───╮              │
│            │ + │              │   ← docked FAB, приподнят, в вырезе
│        ╭───╯───╰───╮          │
│   ▣            ⚙             │
│  Chats        Settings        │   ← 2 слота по краям выреза, иконка + подпись
└───────────────────────────────┘
```

  - **2 таба** по краям выреза, каждый: иконка + текстовая подпись (`Chats`, `Settings`).
  - selected-таб — `ColorScheme.primary` (иконка заполненная + цвет подписи); unselected — `onSurfaceVariant` (иконка контурная). pressed — стандартный M3 ripple/state-layer.
  - **Центральная «+»** — круглый `FloatingActionButton`, docked в вырезе, приподнят (elevation по M3 FAB), иконка `Icons.add`, цвет `ColorScheme.primaryContainer` / `onPrimaryContainer`.
  - Панель **видна на обоих табах**; «+» присутствует на обоих (создание чата доступно и из Chats, и из Settings).

## Состояния

| Состояние | Описание |
|---|---|
| Chats-active | Выбран таб Chats; body = 5.1; иконка Chats — selected. |
| Settings-active | Выбран таб Settings; body = 7.1; иконка Settings — selected. |
| Pushed | Поверх шелла открыт детальный экран; нижняя панель не видна (экран на весь экран со своим back). |

Отдельных loading/error-состояний у самого шелла нет — они принадлежат root-экранам (5.1 / 7.1).

## Взаимодействия

- **Тап по табу** → переключение активного root-экрана; состояние предыдущего таба сохраняется. Повторный тап по активному табу — скролл-в-начало списка (для Chats) / no-op (Settings).
- **Тап по «+»** → push 6.1 поверх шелла. Отмена 6.1 возвращает на тот таб, с которого открыли; после создания шелл переключается на таб **Chats** и открывает ленту нового чата.
- **Аватар аккаунта** (справа в верхней панели 5.1; на широкой ширине — внизу рейла) → таб **Settings**, раздел аккаунта.
- **Системный back / жест back на root-табе:**
  - если активен **не** Chats (т. е. Settings) → переключение на таб **Chats** (не выход);
  - если активен **Chats** → сворачивание приложения (`SystemNavigator.pop`).
- Системный back на pushed-экране — обрабатывается самим pushed-экраном (pop в его стеке), до шелла не доходит.

## Material-компоненты

- `Scaffold` с `bottomNavigationBar: BottomAppBar` и `floatingActionButton` + `floatingActionButtonLocation: FloatingActionButtonLocation.centerDocked`.
- `BottomAppBar` (M3) с `shape: CircularNotchedRectangle` (вырез под FAB).
- `FloatingActionButton` (M3) — центральная «+», `Icons.add`.
- Два кастомных таб-элемента (иконка + подпись) внутри `BottomAppBar` (не `NavigationBar`, т.к. нужен центральный вырез).
- `Stack` из обеих вкладок, каждая в `IgnorePointer` + `AnimatedOpacity` — сохранение состояния табов и смена вкладок плавной прозрачностью.

Иконки табов (Material Symbols Rounded): Chats — `forum`, Settings — `settings`; у выбранного таба — заполненная форма, у невыбранного — контурная.

## Десктоп-раскладка

> Сведена с корпусом `nox-desktop-screens/{01-chats,02-settings}.md` (`specs/006-shell-settings-chats`).

- **Адаптив width-driven** по `Constants.railBreakpoint` (840dp), не по платформе. `< 840` — мобильный bottom-bar + центральный docked `+` FAB; `>= 840` — собственный рейл шириной 80 (не Material `NavigationRail`) **без `+`**: две точки назначения (выбранная — заливка `secondaryContainer`, глиф заполненный) и аватар аккаунта внизу.
- **`+` — в шапке панели чатов**, рядом с заголовком `Chats` (решение владельца 2026-09-20): корпус рисует его leading-кнопкой рейла 56dp, и под двумя точками назначения она оказывалась самым тяжёлым элементом окна — ради действия, которое принадлежит рядом со списком, в который оно создаёт. Следствие, названное прямо: на широкой ширине при открытой вкладке `Settings` кнопки создания нет. На узкой ширине docked `+` — на обеих вкладках.
- Над рейлом и вкладками — заголовок окна `NOX — Chats` / `NOX — Settings` (подпись следует за выбранной вкладкой). Вкладки переключаются плавной сменой прозрачности (`tabFade`), и обе остаются живыми — состояние каждой сохраняется.
- На десктопе вкладки 5.1/7.1 разворачиваются в **list-detail** (детали — в их спеках). `+` на десктопе открывает 6.1 модальным `Dialog` (а не полноэкранным push).
- **Состояние связи** на широкой ширине живёт в правом краю заголовка окна (`AppWindowTitlebarWidget`) и видно на всех экранах оболочки: бейдж `Tor`, `Connecting…`, их сочетание или ничего — по общему правилу [overview / Состояние связи](../overview.md#состояние-связи-в-углу-экрана). На узкой ширине оно в верхних панелях 5.1 и 5.2, а не в оболочке.
