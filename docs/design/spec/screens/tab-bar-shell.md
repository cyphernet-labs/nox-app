# 4.1 Tab bar shell

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 4.1 закрыты 2026-05-29.

## Назначение

Каркас авторизованной части приложения. Содержит нижнюю панель навигации и область контента, в которой рендерятся root-экраны табов. Это единственный кастомный навигационный элемент NOX (не сводится к стандартному `NavigationBar` — см. [overview.md / Дизайн-фреймворк](../overview.md#дизайн-фреймворк)).

Шелл — точка назначения всех пост-логин маршрутов (`1.1 → 4.1`, `2.3 → 4.1`) и контейнер, поверх которого pushed-экраны (5.2, 5.3, 5.4, 6.1, 7.2–7.7) открываются на весь экран **без нижней панели**.

## Контекст и переходы

- **Откуда:** 1.1 Splash (авто-вход) или 2.3 (после онбординга).
- **Внутри (табы, без анимации стека):**
  - таб **Chats** → root-экран 5.1;
  - таб **Settings** → root-экран 7.1.
- **Действие (центральная «+»):** открывает 6.1 (push поверх шелла).
- **Pushed поверх шелла (на весь экран, панель скрыта):** 5.2, 5.3, 5.4 (из Chats-стека), 7.2–7.7 (из Settings-стека), 6.1.

## Лейаут

Material `Scaffold` с кастомной нижней панелью; адаптируется под тему через `ColorScheme`.

- **Body:** активный root-экран таба. Состояние каждого таба **сохраняется** при переключении (паттерн `IndexedStack` — скролл-позиция и ввод не сбрасываются).
- **Нижняя панель — `BottomAppBar` с центральным вырезом (notch) + docked `FloatingActionButton`:**

```
┌───────────────────────────────┐
│            ╭───╮              │
│            │ + │              │   ← docked FAB, приподнят, в вырезе
│        ╭───╯───╰───╮          │
│   ▣            ⚙             │
│  Chats        Settings        │   ← 2 слота по краям выреза, иконка + подпись
└───────────────────────────────┘
```

  - **2 таба** по краям выреза, каждый: иконка + текстовая подпись (`Chats`, `Settings`).
  - selected-таб — `ColorScheme.primary` (иконка заполненная + цвет подписи); unselected — `onSurfaceVariant` (иконка контурная). pressed — стандартный M3 ripple/state-layer.
  - **Центральная «+»** — круглый `FloatingActionButton`, docked в вырезе, приподнят (elevation по M3 FAB), иконка `Icons.add`, цвет `ColorScheme.primaryContainer` / `onPrimaryContainer`.
  - Панель **видна на обоих табах**; «+» присутствует на обоих (создание чата доступно и из Chats, и из Settings).

## Состояния

| Состояние | Описание |
|---|---|
| Chats-active | Выбран таб Chats; body = 5.1; иконка Chats — selected. |
| Settings-active | Выбран таб Settings; body = 7.1; иконка Settings — selected. |
| Pushed | Поверх шелла открыт детальный экран; нижняя панель не видна (экран на весь экран со своим back). |

Отдельных loading/error-состояний у самого шелла нет — они принадлежат root-экранам (5.1 / 7.1).

## Взаимодействия

- **Тап по табу** → переключение активного root-экрана; состояние предыдущего таба сохраняется. Повторный тап по активному табу — скролл-в-начало списка (для Chats) / no-op (Settings).
- **Тап по «+»** → push 6.1 поверх шелла. Возврат из 6.1 — на тот таб, с которого открыли (исходный таб запоминается шеллом).
- **Системный back / жест back на root-табе:**
  - если активен **не** Chats (т. е. Settings) → переключение на таб **Chats** (не выход);
  - если активен **Chats** → сворачивание приложения (`SystemNavigator.pop`).
- Системный back на pushed-экране — обрабатывается самим pushed-экраном (pop в его стеке), до шелла не доходит.

## Material-компоненты

- `Scaffold` с `bottomNavigationBar: BottomAppBar` и `floatingActionButton` + `floatingActionButtonLocation: FloatingActionButtonLocation.centerDocked`.
- `BottomAppBar` (M3) с `shape: CircularNotchedRectangle` (вырез под FAB).
- `FloatingActionButton` (M3) — центральная «+», `Icons.add`.
- Два кастомных таб-элемента (иконка + подпись) внутри `BottomAppBar` (не `NavigationBar`, т.к. нужен центральный вырез).
- `IndexedStack` — сохранение состояния табов.

Иконки табов (Material): Chats — `Icons.forum_outlined` / `Icons.forum` (selected); Settings — `Icons.settings_outlined` / `Icons.settings` (selected).

## Десктоп-раскладка (этап M3, сверено с корпусом)

> Добавлено при реализации M3 (`specs/006-shell-settings-chats`). Верхняя часть спеки описывает мобильный bottom-bar; десктоп-раскладка сведена с авторитетным корпусом `nox-desktop-screens/{01-chats,02-settings}.md`.

- **Адаптив width-driven** по `Constants.railBreakpoint` (840dp), не по платформе. `< 840` — мобильный bottom-bar + центральный docked `+` FAB; `>= 840` — `NavigationRail` с `+` как **leading** FAB (позиция leading — решение реализации; корпус лишь требует `+` на рейле).
- Реализация — `TabBarShell` на kit-виджетах (`AppBottomBarWidget`/`AppCreateFabWidget`/`AppNavigationRailWidget`), заменяет верификационный Feature-001 `AppShell`. Состояние вкладки — локальное (`StatefulWidget`, без BLoC); `IndexedStack`-эквивалент с `tabFade`.
- На десктопе вкладки 5.1/7.1 разворачиваются в **list-detail** (детали — в их спеках). `+` на десктопе открывает 6.1 модальным `Dialog` (а не полноэкранным push).
