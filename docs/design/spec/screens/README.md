# Детальные спецификации экранов

Каждый экран из [карты](../top-level-screens.md) разворачивается в отдельный файл этой папки. Назначение — материал для передачи дизайнеру и для согласования копирайта.

Общие договорённости (модель чата, идентичность, Material Design 3, темизация, лимиты, глобальные UI-конвенции) — в [overview.md](../overview.md). Здесь — только то, что специфично для конкретного экрана.

## Шаблон спецификации

Каждый файл придерживается одной структуры; разделы, неприменимые к конкретному экрану, опускаются явно. Допускаются дополнительные screen-specific секции (например «Параметры экрана» у 3.1, «Анимация» у 1.1), но «Принятые решения» всегда идёт последней.

1. **Назначение** — одна-две строки о роли экрана.
2. **Контекст и переходы** — откуда сюда попадают, куда уходят.
3. **Лейаут / содержимое** — регионы, расположение, ключевые элементы.
4. **Состояния** — типовой вокабуляр (английские ключи): `Initial-loading`, `Loading`, `Empty`, `Loaded` / `Filled`, `<...>-error` (inline), `Fatal`, плюс screen-specific (`Sending`, `Checking-availability`, и т. п.).
5. **Взаимодействия** — тапы, жесты, поведение клавиатуры, системные кнопки.
6. **Material-компоненты** — конкретные M3-компоненты, на которые опираемся.
7. **Микрокопирайт** — все строки, видимые пользователю (на английском).
8. **Принятые решения** — таблица `# / Вопрос / Решение` по закрытым вопросам экрана. (Секция «Открытые вопросы» в файле остаётся только пока есть незакрытые вопросы; после закрытия всех — удаляется.)
