# 2.1 Вход по ссылке спаривания

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 2.1 (Q1–Q9) закрыты 2026-05-28.

## Назначение

Точка входа в спаривание: человек предъявляет ссылку `nox://pair/…` версии 3 — ссылку с машины сервера (её показывает служебная страница и печатает `noxd link`) или приглашение, которое выпустило другое его устройство. Ссылка несёт ключ сервера, одноразовый токен и адреса сервера. Экран ссылку **только читает**: нечитаемую и ссылку новее приложения отклоняет сам, читаемую передаёт экрану подключения [2.4](connect.md), который и спаривает. Альтернативы вставке — сканирование QR (2.2) там, где есть камера, и картинка с QR-кодом на Windows и Linux.

Входа по идентификатору нет: устройство доказывает владение своим ключом, а ключ никуда не уезжает.

## Контекст и переходы

- **Откуда:**
  - 1.1 Splash — устройство не спарено (первый запуск или после Logout с полной очисткой).
- **Куда:**
  - **2.4 Подключение к серверу** — читаемая ссылка, каким бы способом она ни пришла: `Sign in` (или Enter) после вставки, успешный скан в 2.2, картинка с QR-кодом. Возврат из 2.4 (стрелка, `Cancel`, системный back) оставляет ссылку в поле.
  - **2.4 Подключение к серверу — сразу при открытии**, если приложение закрыли во время ожидания подтверждения приглашения, а срок ожидания ещё не вышел: 2.1 передаёт 2.4 ту же ссылку с теми же настройками, и 2.4 сразу предъявляет её снова (состояние Resumed в [connect.md](connect.md)). Ожидание, срок которого вышел, 2.1 не предлагает: его следы стёрты, экран открывается как обычно.
  - **2.2 Сканирование QR** — по тапу `Scan QR` (iOS, Android, macOS).
    - **Возврат через back / `Enter manually`** — содержимое поля 2.1 сохраняется.
    - **Возврат после успешного скана** — 2.2 закрывается сама, ссылка подставляется в поле 2.1 и **сразу** читается (override 2.1 Q5 «только по тапу»: сам акт скана — действие пользователя, эквивалентное submit'у); читаемая ведёт в 2.4.

**Системный back / жест back** — свернуть приложение (стандарт корневого экрана; `SystemNavigator.pop`).

## Лейаут

Каркас `AppOnboardingScaffoldWidget`: поле, которое прокручивается, над закреплённым блоком действий.

**Узкая ширина.** Material Scaffold с `resizeToAvoidBottomInset: true`; фон — `ColorScheme.surface`. Сверху вниз:

1. **Верх:** M3 `AppBar` с wordmark `NOX` и брендовой градиентной линией.
2. **Центр:** моноширинное многострочное поле ссылки — коробка фиксированной высоты (~120dp), длинная ссылка переносится и прокручивается внутри. В правом верхнем углу поля — действие `Paste`. При ошибке — `errorText` под полем.
3. **Низ:** primary `Sign in` на всю ширину, под ним secondary `TextButton`: `Scan QR` там, где есть сканер камерой (iOS, Android, macOS), или `Use a QR image` на Windows и Linux.

**Широкая ширина.** Заголовок окна `NOX — Sign in`; по центру — онбординг-карта (логотип, wordmark, градиентная пилюля) с тем же полем и теми же кнопками.

## Состояния

| Состояние | Описание |
|---|---|
| Empty | Поле пустое. `Sign in` disabled. `Paste` disabled, если буфер обмена пуст. |
| Filled | В поле есть содержимое. `Sign in` enabled. |
| Inline-error (не ссылка) | Содержимое не читается как ссылка спаривания: не ссылка, обрезанная ссылка или формат старше версии 3. `errorText` под полем. Следующее действие — вставить или отсканировать ссылку заново. |
| Inline-error (ссылка новее приложения) | Ссылка разобралась до номера версии, и он больше 3: её выпустил сервер новее приложения. Своя строка: следующее действие — обновить приложение, а не сканировать заново. |

Соединения 2.1 не открывает и индикатора загрузки у него нет: всё, что отвечает сервер или путь до него, — отказ токена, срок ссылки, недоступный сервер, чужой ключ — говорит [2.4](connect.md).

## Взаимодействия

- Тап в поле → системная клавиатура поднимается.
- **`Paste`** — всегда отображается. Disabled, если буфер обмена пуст; буфер перепроверяется при возврате приложения на передний план. Тап вставляет содержимое буфера в поле.
- **`Sign in`** — читает ссылку. Auto-submit нет — только по явному действию пользователя. Enter / Go на программной клавиатуре — эквивалент тапу `Sign in`.
- **Правка поля** убирает `errorText`.
- **`Scan QR`** — переход в 2.2 (см. «Контекст и переходы»).
- **`Use a QR image`** (Windows, Linux) — системный выбор файла; QR-код с картинки распознаётся на устройстве и идёт тем же путём, что вставка. Картинка без ссылки спаривания — snackbar `Couldn't read a pairing link from that image.`, поле не меняется. Повторный тап, пока картинка читается, игнорируется.
- **Системный back** — свернуть приложение.

## Material-компоненты

- `Scaffold` с `resizeToAvoidBottomInset: true`.
- `AppBar` (M3) с wordmark `NOX` — узкая ширина; заголовок окна + онбординг-`Card` — широкая.
- `TextField` (M3 outlined), многострочный, моноширинный, без `obscureText`. Действие `Paste` — `IconButton` в правом верхнем углу. `errorText` — стандартный.
- `FilledButton` — primary action.
- `TextButton` — secondary action.
- `SnackBar` (M3, ошибка) — картинка без ссылки.

## Принятые решения (Q1–Q9)

| # | Вопрос | Решение |
|---|---|---|
| Q1 | Формат поля ввода | Многострочное, моноширинное (text wrap) |
| Q2 | Видимость ввода | Открытый текст, без маски |
| Q3 | Клиентская проверка | Только разбор ссылки на устройстве: «не ссылка» и «ссылка новее приложения». Всё, что решает сервер, — на 2.4 |
| Q4 | Кнопка `Paste` | Всегда видна, disabled при пустом буфере |
| Q5 | Auto-submit | Ручной ввод — только по тапу `Sign in` / Enter. **Исключение:** QR-success → программное чтение (см. [qr-scan.md](qr-scan.md)) |
| Q6 | Хедер экрана | M3 AppBar с wordmark `NOX` |
| Q7 | Системный back | Свернуть приложение |
| Q8 | Возврат из 2.2 и 2.4 | Содержимое поля сохраняется |
| Q9 | Где какие ошибки | Разбор ссылки — inline на 2.1; связь, причины неудачи и отказы токена — на [2.4](connect.md) под `Connect` |
| — | Куда ведёт читаемая ссылка | Всегда на 2.4 — при вставке, скане и картинке, на всех платформах (уточнение 2026-10-09) |
| — | Ожидание подтверждения после перезапуска | 2.1 сразу ведёт на 2.4, которая продолжает тот же запрос, пока не вышел его срок (фаза 046, FR-011) |
