# 6.1 Создание чата

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 6.1 закрыты 2026-05-29.

## Назначение

Полноэкранная форма создания нового чата. Открывается по тапу центральной `+` в нижней панели 4.1. Имя чата вводится с **real-time валидацией уникальности** (см. [overview.md](../overview.md#создание-чата)); лимит — 64 символа, **charset не ограничен**. Доступно любому пользователю. **Описания у чата нет** — формой управляется только имя.

**`Create` никогда не ждёт сервер** (фаза 041): чат создаётся на устройстве и открывается сразу — со связью и без неё, на обеих ширинах.

## Контекст и переходы

- **Откуда:** 4.1 Tab bar shell — тап на центральной `+` из любого таба.
- **Куда:**
  - **5.2 Лента чата (нового)** — сразу после нажатия `Create`, без ожидания сервера.
  - Back / cancel → возврат на исходный таб (без подтверждения, даже если поле заполнено).
  - **3.1 Универсальный экран ошибки** — для fatal-сценариев.

## Лейаут

Material **полноэкранный** Scaffold; адаптируется под тему. Сверху вниз:

1. **AppBar (M3):** back-стрелка слева; **title — `New chat`** (текстовый, описывает задачу; wordmark не используется — это pushed-экран, паттерн title как у 5.2/5.4/7.x).
2. **Body:** column:
   - поле имени чата (`TextField` с лимитом 64 + counter + `helperText` / `errorText`).
3. **Низ:** primary `FilledButton` `Create` на всю ширину.

## Состояния

| Состояние | Описание |
|---|---|
| Empty | Поле пустое. `Create` disabled. |
| Checking-availability | Идёт проверка уникальности (debounced ~300 мс): по локальной базе всегда и сервером — только если он может ответить сразу. Suffix-индикатор в поле. |
| Filled-invalid (taken) | Имя занято: так его называет чат на устройстве (в том числе ещё ждущий создания) или ответ сервера. errorText `This name is taken`. `Create` disabled. |
| Filled-valid | Длина OK, имя свободно. `Create` enabled. Сервер, который не ответил на проверку, имя не держит: проверка открыта на отказ. |
| Loading-submit | Чат записывается на устройство. Запись локальная и мгновенная, индикатор внутри primary button практически не виден. |
| Inline-error | Только сбой локальной записи. Сеть сюда не приводит: создание на сервере идёт позже, в очереди. errorText под полем, `Create` снова enabled. |
| Fatal | Передача в 3.1 (embedded). |

Состояния «Filled-invalid (charset)» нет — charset не ограничен.

## Взаимодействия

- Тап в поле → системная клавиатура поднимается.
- Ввод символов → debounced проверка уникальности по локальной базе и сервером, если он отвечает сразу (без локальной charset-валидации).
- **`Create`** или **Enter / Done** → чат создаётся на устройстве и открывается его лента.
- **Back / cancel** → возврат на исходный таб без подтверждения; введённый текст теряется, даже если поле было заполнено.
- **Long-press на поле** — стандартное системное (paste / select).

## Создание без связи (фаза 041)

- **Id чата придумывает устройство**: `c_` и 32 шестнадцатеричных знака в нижнем регистре из криптостойкого генератора. Это id чата навсегда — на устройстве, на сервере и на других устройствах человека; ничего не переставляется.
- Чат появляется в списке (5.1) и открывается (5.2) сразу; в него сразу можно писать — сообщения ждут в очереди с часиками.
- На сервере чат создаёт очередь исходящих — раньше любых его сообщений, как только канал текущий, любым путём (напрямую или через Tor), командой `chat.create` с этим id. Повтор после потерянного ответа возвращает тот же чат: второго не появляется.
- **Окончательно имя проверяет сервер**, когда очередь создаёт чат. Если к этому моменту имя занято (например, такой же чат создан на другом устройстве этого человека), чат помечается «имя занято», его сообщения ждут, а в списке и ленте предлагается переименовать (5.1, 5.2). Переименование делается на устройстве, и создание уходит само.
- Прочий отказ сервера помечает чат «не создан» с действием `Try again` в ленте.

## Material-компоненты

- `Scaffold` (полноэкранный).
- `AppBar` (M3) с title `New chat` и back-стрелкой; адаптируется под тему.
- `TextField` (M3 outlined) с `maxLength: 64`, встроенным counter, `helperText` / `errorText`, suffix-`CircularProgressIndicator` в Checking-availability.
- `FilledButton` — primary action `Create`.
- `CircularProgressIndicator` (внутри primary button) — Loading-submit.
