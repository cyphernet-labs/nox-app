# 7.6 Terms

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 7.6 закрыты 2026-05-29.

## Назначение

Подраздел настроек 7.1. Показ юридической информации (Terms of Service, Privacy Policy). Контент **зашит в приложение** (bundled Markdown или HTML); обновляется только релизами. Acceptance flow **не предусмотрен** — просто просмотр.

## Контекст и переходы

- **Откуда:** 7.1 — тап на `Terms`.
- **Куда:**
  - Back-стрелка → 7.1.
  - Внешние ссылки внутри текста → системный браузер.

## Лейаут

Material Scaffold; адаптируется под тему. Сверху вниз:

- **AppBar (M3):** title `Terms`, back-стрелка.
- **Body (scroll):**
  - Контент Terms — рендерится из bundled-ассета (`flutter_markdown` для Markdown или `webview_flutter` для HTML).
  - **Footer**: версия приложения (`Version 1.2.3`) внизу под текстом.

Last updated date **не показывается** — единственный метаданный footer-элемент — версия приложения.

## Состояния

| Состояние | Описание |
|---|---|
| Loaded | Контент отображается. |
| Inline-error | Сбой рендеринга (редко, т. к. контент локальный) — snackbar. |

## Взаимодействия

- **Скролл** — стандартный.
- **Тап на ссылку внутри текста** → внешний браузер (через системный intent).
- **Тап на back** → 7.1.

## Material-компоненты

- `Scaffold`.
- `AppBar` (M3) с back-стрелкой и title.
- `SingleChildScrollView` + Markdown / WebView widget — основной контент.
- `Text` — footer с версией.

## Микрокопирайт

| Элемент | Текст (EN) |
|---|---|
| AppBar title | `Terms` |
| AppBar back tooltip | `Back` |
