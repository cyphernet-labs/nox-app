# 3.1 Универсальный экран ошибки

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 3.1 закрыты 2026-05-29.

## Назначение

Универсальный параметризованный экран ошибки. Адаптируется под кейс через параметры (вид ошибки, иконка, retry-callback); заголовок и сообщение задаёт вид ошибки. Два режима:

- **Embedded** — со стрелкой back, означающей, что 3.1 **не последний** экран в стеке. Системный back возвращает на предыдущий экран.
- **Blocking** — без AppBar; 3.1 — **последний** экран в стеке. Системный back свёртывает приложение.

Вид ошибки по умолчанию — fatal: заголовок `Something went wrong`.

## Контекст и переходы

Известные точки вызова:

| Источник | Сценарий |
|---|---|
| 2.3 Установка имени | Не удалось завершить онбординг (сохранить выбранное имя или оставить назначенное). |
| 6.1 Создание чата | Fatal-сценарий формы. Живой путь его не производит: создание чата — локальная запись, а её сбой — inline-ошибка формы. |

Где 3.1 **не** используется, хотя ошибка есть:

- **1.1 Splash** — ошибка чтения сессии трактуется как «не спарено», а не как fatal; потерянный ключ локальных данных ведёт к спариванию заново (см. [splash.md](splash.md)).
- **2.1 и 2.4** — всё, что отвечает сервер или путь до него, говорится inline под `Connect` на 2.4.
- **2.2** — недоступная камера показывается на самом экране (`Camera unavailable` + `Enter manually`).
- **5.1, 5.2, 5.4** — сбой загрузки показывается на месте содержимого: глиф ошибки, `Something went wrong` и `Try again`; шапка экрана и связь остаются.
- **5.3** — исчезнувший файл и исчерпанные повторы скачивания — состояния самого экрана.

Переходы:

- **Retry-action** → `onRetry` (определяется вызывающей стороной).
- **Back-стрелка** (только embedded) → возврат на предыдущий экран.
- **Системный back** (embedded) → эквивалент back-стрелке.
- **Системный back** (blocking) → свёртывание приложения.

## Лейаут

Material Scaffold; цвета адаптируются под тему через `ColorScheme`. Сверху вниз:

- **Embedded:**
  1. `AppBar` (M3) с back-стрелкой; адаптируется под тему.
  2. Центр (column): иконка → заголовок (`Headline Small`) → сообщение (`Body Medium`, `onSurfaceVariant`) → primary `FilledButton` с retry-текстом.
- **Blocking:**
  1. Без `AppBar` — full-screen.
  2. Центр (column): иконка → заголовок → сообщение → primary `FilledButton` с retry-текстом.
- **Широкая ширина:** сверху заголовок окна `NOX — Error`; в embedded-режиме стрелка back — в левом верхнем углу над телом. Тело то же.

Иконка — **увеличенная, 48–96dp** (на широкой ширине крупнее, чем на узкой), `onSurfaceVariant`. Глиф — `error_outline` из набора Material Symbols Rounded (§8 [design-system](../design-system.md)).

## Состояния

| Состояние | Описание |
|---|---|
| Embedded | Со стрелкой back; retry-action доступен. |
| Blocking | Без AppBar; пользователь может тапнуть retry или свернуть приложение системным back. |
| Loading-retry | После тапа retry — кнопка disabled, внутри `CircularProgressIndicator`. Пока вызывающая сторона не переключит экран. |

Появление экрана — **без анимации** (мгновенный показ).

## Взаимодействия

- **Retry-action** → вызов `onRetry`; кнопка переходит в Loading-retry.
- **Back-стрелка** (embedded) → возврат на предыдущий экран.
- **Системный back** (embedded) → эквивалент back-стрелке.
- **Системный back** (blocking) → свёртывание приложения.
- **При retry → новая ошибка**: содержимое текущего 3.1 **обновляется** новыми параметрами; стек не растёт (нет 3.1 поверх 3.1).

## Параметры экрана

| Параметр | Тип | Описание |
|---|---|---|
| `mode` | enum | `blocking` или `embedded` |
| `kind` | enum | `fatal` или `network` — выбирает заголовок и сообщение (см. «Микрокопирайт») |
| `icon` | глиф | иконка ошибки; по умолчанию `error_outline` |
| `onRetry` | callback (опц.) | действие при тапе retry |

Заголовок, сообщение и текст retry-action параметрами не передаются — они **локализуются** по виду ошибки (English / Українська / системный с fallback на English; см. правило локализации в [overview.md](../overview.md)). Back в embedded-режиме возвращает на предыдущий экран.

## Material-компоненты

- `Scaffold`.
- `AppBar` (M3, только embedded на узкой ширине) — с back-стрелкой; адаптируется под тему.
- Глиф — увеличенный, 48–96dp, Material Symbols Rounded (default — `error_outline`).
- `Text` — заголовок и сообщение.
- `FilledButton` — retry-action.
- `CircularProgressIndicator` (внутри primary button) — Loading-retry.

## Микрокопирайт

UI-тексты — на английском (см. [overview.md / Терминология и брендинг](../overview.md#терминология-и-брендинг)). Кнопка retry-action **локализуется** во время сборки; в спецификации фиксируется English.

| Элемент | Текст (EN) |
|---|---|
| Retry-action button | `Try again` |
| AppBar back tooltip (embedded) | `Back` |
| AppBar title (embedded) | `(empty)` |
| Заголовок окна (широкая) | `NOX — Error` |

Тексты по виду ошибки:

| `kind` | Title | Message |
|---|---|---|
| `fatal` | `Something went wrong` | `An unexpected error occurred. Please try again.` |
| `network` | `No connection` | `Could not connect. Check your connection and try again.` |

## Принятые решения (Q1–Q9)

| # | Вопрос | Решение |
|---|---|---|
| Q1 | Системный back и режимы | Embedded со стрелкой back = не последний в стеке (back возвращает на предыдущий экран). Blocking без AppBar = последний в стеке (back свёртывает приложение). |
| Q2 | Текст retry-action | Локализуется (English / Українська / системный с fallback на English); в спеках фиксируем `Try again` |
| Q3 | Loading-retry | Индикатор внутри кнопки (disabled + spinner) |
| Q4 | Default-иконка | Есть default (`error_outline`) |
| Q5 | Размер иконки | Увеличенная, 48–96dp |
| Q6 | Источник иконок | Material Symbols Rounded — тот же набор, что во всём приложении |
| Q7 | AppBar в blocking | Без AppBar |
| Q8 | Анимация появления | Без анимации |
| Q9 | Stacking при retry-fail | Замена содержимого текущего 3.1 (стек не растёт) |
