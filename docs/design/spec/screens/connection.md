# 7.10 Связь

> **Настройки** · экран фазы 045. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Решения владельца 6 и 8 темы 2 трекера безопасности ([roadmap-security.md](../../../client-backend/roadmap-security.md)).

## Назначение

Те же адрес сервера, onion-адрес и `Use Tor`, что на экране подключения [2.4](connect.md), — после спаривания. Здесь человек поправляет адреса, когда до сервера не достучаться, вписывает новый onion-адрес переехавшего сервера без повторного спаривания и включает или выключает Tor. Отсюда же видно, почему нет связи.

## Контекст и переходы

- **Откуда:**
  - узкая ширина — строка `Connection` в [7.1](settings-root.md), сразу под `Devices`; открывается отдельным экраном;
  - широкая ширина — пункт `Connection` в первой группе меню настроек (`Account`, `Devices`, `Connection`); содержимое занимает панель деталей, без push.
- **Куда:** назад в 7.1 (стрелка назад или системный back на узкой ширине; на широкой — выбор другого пункта меню).

## Лейаут

### Узкая ширина (`_narrow`) — [nox-mobile-screens / 7-10-connection](../../system/nox-mobile-screens/screens/7-10-connection.md)

`AppDetailScaffoldWidget`: панель со стрелкой назад и заголовком `Connection`, под ней брендовая градиентная линия. Тело прокручивается, сверху вниз:

1. **Строка причины** — только пока связи нет: текст причины цвета ошибки, а если причина не известна — `No connection`.
2. **Поле `Server address`** (outlined, одна строка).
3. **Поле `Onion address`** (outlined, одна строка); пока поле пустое, под ним `Optional`.
4. **`Save`** — `FilledButton` на всю ширину.
5. **`Could not save. Try again.`** — по центру, цвета ошибки; только если запись не удалась.
6. **Карточка с `Use Tor`** — строка-переключатель: ведущий глиф `lan` (22, `onSurfaceVariant`), заголовок `Use Tor`, подпись `NOX uses Tor only when it can't reach your server directly.`, переключатель справа.

Поля — те же, что на 2.4 (`AppConnectionFieldsWidget`): клавиатура для адресов, без автозамены и подсказок, без счётчика.

### Широкая ширина (`_wide`) — [nox-desktop-screens / 12-connection](../../system/nox-desktop-screens/screens/12-connection.md)

- Пункт меню `Connection` с глифом `lan`; выбранный пункт заливается `secondaryContainer`, глиф меняется на заполненный (`lan` FILL), как у остальных пунктов меню.
- Панель деталей: заголовок панели `Connection`, под ним то же тело, что на узкой ширине (`ConnectionBody`), в колонке не шире 680.

## Что в полях

| Поле | Значение |
|---|---|
| `Server address` | ручная правка человека; если её нет — публичный адрес, который сообщил сервер; если и его нет — прямой адрес из ссылки спаривания |
| `Onion address` | ручная правка; если её нет — onion-адрес, который сообщил сервер (из ссылки — до первого приветствия); пусто — onion-адреса нет |
| `Use Tor` | как человек отметил на 2.4 или здесь |

**Адреса сервера — источник истины** (уточнение 2026-10-09): адрес, который сервер сообщает о себе, заменяет ручную правку того же поля; ручная правка нужна, когда до сервера не достучаться, и действует, пока сервер не сообщит новый. Сервер, у которого публичного адреса нет, вписанный человеком адрес не стирает.

Адреса в локальной сети, которые сообщает сервер, приложение пробует само и в поле не показывает.

## Состояния

| Состояние | Описание |
|---|---|
| Initial-loading | Настройки читаются: по центру `CircularProgressIndicator`. |
| Loaded | Поля показывают действующие значения, `Save` неактивна. |
| Edited | Значение поля изменено и проходит проверку формата: `Save` активна. |
| Field-error | Изменённое поле не проходит проверку формата: под ним `This isn't a valid server address.` или `This isn't a valid onion address.`, `Save` неактивна. Ошибка показывается сразу при наборе — без неё неактивная кнопка ничего бы не объясняла. |
| Saving | Запись идёт: поля и `Save` заблокированы. |
| Save-error | Запись не удалась: `Could not save. Try again.` под `Save`; правка остаётся в полях. Строку убирает следующая правка. |
| Offline | Связи нет: над полями строка причины цвета ошибки, а без известной причины — `No connection`. Та же причина, что на плашках 5.1, 5.2 и 5.4, включая onion-адрес, который отверг Tor-модуль (`This isn't a valid onion address.`): у поля показывается только ошибка формата вписанного. |

Ключ сервера не показывается.

## Взаимодействия

- **`Save`** применяет оба поля адресов сразу. Значение, совпадающее с тем, что сообщает сервер (или со ссылкой, пока сервер ничего не сообщил), правкой не считается: поле снова следует за сервером. Пустое поле onion-адреса — «onion-адреса нет». Сразу после записи приложение подключается заново по новым данным. Сменившийся onion-адрес просто вписывается — повторного спаривания нет (решение владельца 6).
- **`Use Tor`** применяется в момент переключения, без `Save`, и сразу запускает подключение заново. Выключенная галочка останавливает Tor тут же, а соединение, которое шло через Tor, рвётся: дальше — только напрямую. Если переключение не удалось записать, переключатель возвращается назад и под `Save` появляется `Could not save. Try again.`.
- **Адреса от сервера, пока раздел открыт.** Новые адреса, которые сообщил сервер, сразу появляются в полях, которых человек не трогал; поле, которое человек сейчас правит, сохраняет набранное.
- **Строка причины** появляется и уходит сама вместе с состоянием связи; для экранного диктора это живая область.

## Принятые решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Когда применяются правки | Адреса — кнопкой `Save` (активна, когда значение изменено и проходит проверку формата); `Use Tor` — сразу при переключении; подключение заново — сразу после применения (уточнение 2026-10-09) |
| 2 | Чьи адреса действуют | Сервера: его новое значение заменяет ручную правку того же поля; ручная правка действует, пока сервер не сообщит новое (уточнение 2026-10-09) |
| 3 | Переезд onion-адреса | Новый адрес вписывается вручную, без повторного спаривания (решение владельца 6) |
| 4 | Где видна причина | Строкой над полями, пока связи нет; те же тексты, что на плашках 5.1, 5.2, 5.4 |
| 5 | Место в настройках | Узкая ширина — строка сразу под `Devices`; широкая — первая группа меню (`Account`, `Devices`, `Connection`) |
| 6 | Значок | `lan` из того же пакета Material Symbols, что остальные; заполненная форма — у выбранного пункта меню |
