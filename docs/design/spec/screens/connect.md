# 2.4 Подключение к серверу

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Экран фазы 045: решения владельца 4, 8 и 9 темы 2 трекера безопасности ([roadmap-security.md](../../../client-backend/roadmap-security.md)).

## Назначение

Шаг между ссылкой спаривания и самим спариванием. Показывает, куда ведёт ссылка, — адрес сервера и onion-адрес, — даёт их поправить и решить, можно ли идти через Tor. Правка адреса безопасна: кто бы ни ответил по адресу, он обязан доказать ключ сервера, названный ссылкой, и только после этого получает токен. Поэтому сам ключ сервера экран не показывает и править не даёт.

## Контекст и переходы

- **Откуда:** 2.1 — при любом способе получить ссылку: вставка или набор и `Sign in` (Enter), скан камерой (2.2 возвращает ссылку в поле 2.1), картинка с QR-кодом (`Use a QR image` на Windows и Linux). 2.1 только читает ссылку: нечитаемую и ссылку новее приложения отклоняет у себя, любую читаемую ведёт сюда. Путь один на всех платформах.
- **Куда:**
  - **2.3 Установка имени** — спаривание завело личность (claim своего сервера).
  - **4.1 Tab bar shell** — спаривание по приглашению: личность уже есть, выбирать имя не нужно.
  - Переход делает app-state-спина приложения, как после любого входа; экран подключения уходит вместе со всем онбордингом.
  - **2.1** — стрелкой назад (узкая ширина), `Cancel` (обе ширины) или системным back. Ссылка остаётся в поле 2.1.

**Системный back** — назад в 2.1; во время подключения заблокирован (см. «Подключение»).

## Что подставлено из ссылки

| Поле | Значение |
|---|---|
| `Server address` | первый прямой адрес ссылки — публичный адрес сервера, если сервер его задал (ссылка несёт адреса в порядке «публичный → прямой → onion») |
| `Onion address` | `<56 символов>.onion`, выведенный из ключа onion-сервиса в ссылке, без порта; пусто, если ссылка onion-адреса не несёт |
| `Use Tor` | выключена |

Остальные адреса из ссылки и всё, что сервер сообщит о себе после спаривания, приложение пробует само — в поля они не попадают.

## Состояния

| Состояние | Описание |
|---|---|
| Filled | Поля заполнены из ссылки, `Use Tor` выключена, `Connect` доступна. |
| No onion address | Ссылка без onion-адреса: поле `Onion address` пустое, под ним `Optional`. Подсказка видна, только пока поле пустое. |
| Field-error | Человек нажал `Connect`, а исправленное значение не проходит проверку формата: под полем `This isn't a valid server address.` или `This isn't a valid onion address.`, ничего никуда не уходит. С этого момента ошибки поля пересчитываются при каждом изменении. |
| Connecting | Внутри `Connect` — индикатор; поля, `Use Tor`, стрелка назад и `Cancel` заблокированы, системный back не работает. Причина, найденная во время попытки, появляется под кнопкой сразу, не дожидаясь конца попытки. |
| Failed | Одна строка цвета ошибки под `Connect`: текст причины, если она известна, иначе `Could not sign in. Check your connection and try again.` Неверный onion-адрес — у самого поля, а не под кнопкой. Любая правка поля или галочки убирает строку. |
| Link-expired | Сервер ответил, что срок ссылки истёк: `This link has expired. Ask for a new one.` под `Connect`. |
| Link-rejected | Сервер отказался принять токен: `This link can't be used. Ask for a new one.` под `Connect`. |

Ключ сервера не виден ни в одном состоянии.

## Проверка формата

Проверяется только **исправленное**: значение, совпадающее с подставленным из ссылки, принимается как есть.

- **Адрес сервера** — `host:port`: IPv4, IPv6 в квадратных скобках или DNS-имя (метки из букв, цифр и дефиса, до 63 символов каждая и до 253 всего), порт 1–65535. Onion-имя сюда не подходит: у него своё поле, и идёт оно только через Tor.
- **Onion-адрес** — версии 3: 56 символов base32 и `.onion`, в любом регистре, можно с `:443`; последний байт называет версию 3, контрольную сумму проверяет Tor-модуль приложения.

## Взаимодействия

- **Правка полей** — в любой момент, кроме подключения. Правка отменяет то, что сказала прошлая попытка.
- **`Use Tor`** — переключается тапом по строке; применяется вместе с остальным по `Connect`.
- **`Connect`** — проверка формата; затем спаривание с этими настройками. Связь идёт как всегда: сначала напрямую — по адресам ссылки и по вписанному; через Tor — только если `Use Tor` включена и onion-адрес известен, после того как напрямую никто не ответил. Так спаривается и самое первое устройство (claim), и следующие. Токен уходит только по соединению, где сервер доказал ключ из ссылки: машина с другим ключом токена не видит.
- **Что сохраняется:** поле, изменённое человеком, — как его ручная правка, пустое поле onion-адреса — как «onion-адреса нет», `Use Tor` — как отмечено. Дальше эти значения живут в разделе [7.10 Связь](connection.md).
- **Стрелка назад / `Cancel` / системный back** — назад в 2.1, ссылка остаётся в поле.

Отправка — только кнопкой `Connect`; Enter в поле её не запускает.

## Причины неудачи

Причина приходит из выбора пути (общая для всего приложения, см. [overview / Причины неудачи](../overview.md#причины-неудачи)). На этом экране:

| Причина | Где | Текст |
|---|---|---|
| неверный onion-адрес | у поля `Onion address` | `This isn't a valid onion address.` |
| никто не отвечает по onion-адресу | под `Connect` | `No server answers at this onion address. Check the address and that Tor is running on the server.` |
| сервер не отвечает через Tor | под `Connect` | `Your server isn't answering through Tor right now. Check that it is running.` |
| за onion-адресом другой сервер | под `Connect` | `This onion address belongs to a different server.` |
| нет сети Tor | под `Connect` | `Can't connect to the Tor network. Check your internet connection.` |
| напрямую не вышло, `Use Tor` выключена, onion-адрес есть | под `Connect` | `Can't reach the server directly. Turn on Use Tor to connect through Tor.` |

Это и есть подсказка включить `Use Tor` (решение владельца 4): она появляется только тогда, когда галочка что-то изменит.

## Принятые решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Когда открывается экран | После любой читаемой ссылки — вставка, скан, картинка с QR-кодом; путь один на всех платформах (уточнение 2026-10-09) |
| 2 | Сколько полей адреса | Одно поле `Server address`: публичный адрес, если сервер его задал, иначе прямой адрес ссылки. Адреса в локальной сети, которые сервер сообщит позже, приложение пробует само и в поле не показывает (уточнение 2026-10-09) |
| 3 | Ключ сервера | Не показывается и не правится: защиту даёт его проверка на каждом соединении, а не адрес |
| 4 | `Use Tor` по умолчанию | Выключена; подпись говорит, что Tor включается, только когда напрямую не достучаться |
| 5 | Спаривание через Tor | Разрешено — и первого устройства, и следующих (решение владельца 9) |
| 6 | Где причина неудачи | Под `Connect`; неверный onion-адрес — у поля (уточнение 2026-10-09) |
| 7 | Отказы токена | Под `Connect`, и различимы: истёкшая ссылка и ссылка, которую нельзя использовать, — разные строки. 2.1 к серверу не обращается и отказов токена не показывает |
| 8 | Назад на широкой ширине | Только `Cancel`: у окна нет панели приложения со стрелкой |
