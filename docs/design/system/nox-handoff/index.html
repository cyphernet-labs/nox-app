NOX

Flutter handoff package

The NOX design system, exported as machine-readable design tokens and ready-to-drop Flutter code. Built for Material Design 3, light + dark. No screenshots — every value is parseable by a token pipeline or a code generator.

W3C Design Tokens (DTCG) Flutter / Material 3 Light + Dark Generated from src/tokens.jsx

Two ways to consume

tokens/*.tokens.json

A · Generate from tokens

Standards-compliant W3C Design Tokens JSON. Feed to Style Dictionary, Tokens Studio, or a custom generator to emit Dart / Kotlin / Swift / CSS. $metadata.json gives load order.

flutter/*.dart

B · Drop in the Dart

The same data already transformed to Flutter — ColorScheme, TextTheme, ThemeData + token constants. Copy into lib/theme/ and go.

MaterialApp(
  theme: noxLightTheme,
  darkTheme: noxDarkTheme,
  themeMode: ThemeMode.system,
);
