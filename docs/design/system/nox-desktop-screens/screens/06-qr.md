# 03 · QR scan

> ⚠️ **Feature 032:** the scanner reads a pairing link, not `nox://id/`, and passes the WHOLE payload on — the server address and its key are needed as much as the token. Windows and Linux have no camera: the same parser runs over a picked image there, and pasting text works everywhere.

> **03 · Onboarding** · desktop (Windows / Linux / macOS) · Material 3 · window 1440×900

**Purpose.** Scan an ID QR with the webcam, or fall back to manual entry.

**Adaptation from mobile.** mobile full-screen camera → windowed viewfinder; permission state reuses the onboarding card

## Anatomy
Title bar (NOX · Scan QR) + centered viewfinder (300, brand-white corners) + helper with a manual-entry link. Denied → OnboardCard with no_photography + Open settings.

## States
- `scan` — Scanning
- `denied` — Permission denied

## Behavior
- Webcam feed inside the viewfinder; valid code signs in. Manual-entry link routes to Login.
- Permission denied → card with explanation + Open settings (system).

## Navigation
- Valid scan → Set username / Chats.
- Enter manually → Login (03).
- Open settings → OS settings.

## Copy (EN)
- Title: Scan a QR code
- Helper: Point your webcam at a code, or enter the ID manually.
- Denied: Camera access needed / To scan a QR code, allow camera access in system settings. / Open settings

## Design-system components
- DesktopWindow + TitleBar
- Viewfinder
- OnboardCard (denied)
