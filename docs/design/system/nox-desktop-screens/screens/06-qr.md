# 03 · QR scan

> ⚠️ **Feature 032, link format from 044, Connect from 045:** the scanner reads a pairing link `nox://pair/…` (version 3), not `nox://id/`, and passes the WHOLE payload on — the server's key and addresses are needed as much as the token. A code with no pairing link in it is refused here; a link from a newer app goes on to Login, which says to update the app. A scanned link takes the same path as a pasted one: Login reads it and opens Connect. Windows and Linux have no camera: the same parser runs over a picked image there (“Use a QR image” on Login), and pasting text works everywhere.

> **03 · Onboarding** · desktop (Windows / Linux / macOS) · Material 3 · window 1440×900

**Purpose.** Scan a pairing link's QR code with the webcam (macOS), or fall back to manual entry.

**Adaptation from mobile.** mobile full-screen camera → windowed viewfinder; permission state reuses the onboarding card

## Anatomy
Title bar (NOX · Scan QR) + centered viewfinder (300, brand-white corners) + helper with a manual-entry link. Denied → OnboardCard with no_photography + Open settings.

## States
- `scan` — Scanning
- `denied` — Permission denied

## Behavior
- Webcam feed inside the viewfinder. A scanned pairing link closes the scanner and goes into the Login field, and Login reads it and opens Connect (03) at once (feature 045). A code with no pairing link → snackbar “This QR code is invalid. Try another one.”; scanning goes on. Manual-entry link routes to Login.
- Permission denied → card with explanation + Open settings (system).

## Navigation
- Valid scan → Login (03), which opens Connect (03) at once.
- Enter manually → Login (03).
- Open settings → OS settings.

## Copy (EN)
- Title: Scan a QR code
- Helper: Point your webcam at a code, or enter the ID manually.
- Denied: Camera access needed / To scan a QR code, allow camera access in system settings. / Open settings
