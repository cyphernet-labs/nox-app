# Дизайн NOX

Документация по дизайну и UI приложения: верхнеуровневые экраны, навигация, разделы, компоненты, спецификации макетов.

Технические темы (протоколы, шифрование, серверная часть, кодовая архитектура) сюда **не входят** — они описываются в других папках `docs/`.
