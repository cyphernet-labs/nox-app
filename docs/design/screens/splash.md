# 1.1 Splash

> Детальная спецификация экрана. Часть [карты экранов](../top-level-screens.md). Общие решения — в [overview.md](../overview.md). Все верхнеуровневые открытые вопросы по 1.1 закрыты 2026-05-28.

## Назначение

Стартовый экран приложения. Показывает лого с подписью «NOX», проигрывает короткую анимацию появления, проверяет состояние авторизации и маршрутизирует пользователя дальше.

## Контекст и переходы

- **Откуда:** **только холодный старт** приложения (запуск с нуля после kill, открытие из иконки, открытие по push, когда процесс не висит в памяти). При **тёплом возврате из бэкграунда** splash **не показывается** — пользователь сразу возвращается на экран, на котором был.
- **Куда:**
  - идентификатор сохранён локально → **4.1 Tab bar shell** (авто-вход);
  - идентификатора нет → **2.1 Вход по идентификатору**;
  - ошибка чтения локального состояния (повреждение, отсутствие доступа) → **3.1 Универсальный экран ошибки** в блокирующем режиме.

Переход к следующему экрану происходит **не раньше, чем завершится анимация появления** (см. ниже) — даже если состояние авторизации проверено быстрее. Возврат на splash из других экранов не предусмотрен.

## Лейаут

- Полноэкранный Material-Scaffold. Фон — токен **`brand/canvas-dark` (#0C2424)**, фиксированный (**не** из `ColorScheme`): splash одинаков в светлой и тёмной теме. Это одно из двух исключений из темизации (второе — QR-код в 7.1; см. [design-system](../design-system.md)).
- В геометрическом центре экрана — **цветной логотип NOX**. Стилистический ориентир — маска в разноцветных штрихах на тёмном фоне.
- Непосредственно под лого — wordmark **«NOX»** **системным шрифтом** (Roboto на Android / SF Pro на iOS).
- Между лого и wordmark — небольшой вертикальный отступ (точное значение — за дизайн-системой).
- Системные status bar и navigation bar отображаются прозрачно поверх фона (edge-to-edge).
- На экране нет других элементов: текста, кнопок, индикаторов прогресса.

## Анимация появления

Лого и wordmark анимируются **параллельно (вместе)** как единая группа: два эффекта одновременно.

| Параметр | От | До |
|---|---|---|
| Прозрачность (opacity) | 0 | 1 |
| Scale | 0.85 | 1.0 |

Параметры:

- **Длительность** — ~400 мс.
- **Easing** — decelerated (M3 «emphasized decelerate»). Метафора «появление из ниоткуда» — быстрое начало, мягкое замедление к финалу.
- **Точка отсчёта scale** — геометрический центр группы (лого + wordmark).
- После завершения — статика. Никаких циклических / loop-эффектов, никаких пульсаций.

## Состояния

| Состояние | Описание | UI |
|---|---|---|
| Routing | Splash виден от старта приложения до маршрутизации | Лого + wordmark, в процессе и после анимации |
| Fatal | Не удалось прочитать локальное состояние | Передача управления 3.1 в блокирующем режиме |

Отдельного состояния «загрузка» нет: индикатор прогресса не показываем. Если состояние авторизации проверено до окончания анимации, маршрутизация всё равно дожидается её завершения.

## Взаимодействия

- Экран пассивный: тапы, свайпы и системные жесты back не вызывают действий.
- Системные жесты ОС работают штатно (свернуть приложение, переключиться на другое).

## Material-компоненты

- `Scaffold` — корневой контейнер с **фиксированным тёмным бренд-фоном** (не зависит от `ColorScheme` / темы).
- `Image` или `SvgPicture` — логотип.
- `Text` системным шрифтом — wordmark «NOX».
- Анимация — через `AnimationController` + `FadeTransition` + `ScaleTransition` (стандартные Flutter-примитивы; внешний пакет вроде Lottie на этом этапе избыточен).

## Принятые решения (Q1–Q5)

| # | Вопрос | Решение |
|---|---|---|
| Q1 | Логотип: монохром / цвет | Цветной; референс — `assets/logo-reference.png` |
| Q2 | Шрифт wordmark | Системный (Roboto / SF Pro) |
| Q3 | Параметры анимации | Baseline: ~400 мс, decelerated, scale 0.85 → 1.0 |
| Q4 | Порядок лого / wordmark | Параллельно (единая группа) |
| Q5 | Восстановление из бэкграунда | Splash только при холодном старте; при тёплом возврате — сразу прежний экран |
| — | Тема splash | Brand-fixed **всегда тёмный** (исключение из темизации; фон не из `ColorScheme`) |
