# Протокол обмена

Контракт между приложением и client-сервером, а в дальнейшем — между клиентским и relay-сервером.

**Транспорт:** приложение общается **исключительно** со своим client-сервером по постоянному двунаправленному соединению (WebSocket поверх TLS), то есть в модели publish/subscribe, а не request/response. Байты файлов и доставка при убитом приложении идут вне сокета — см. `wire-surface.md` §6.

**Чем этот раздел отличается от соседних.** `../research/` изучает чужие решения и ничего не предписывает. Здесь — наш собственный контракт: то, что реализуют обе стороны. Пока раздел в состоянии черновика, решения помечены как открытые и ведутся в [реестре](../open-questions.md).
