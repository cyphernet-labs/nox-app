# Протокол обмена

Контракт между приложением и клиентским сервером, а в дальнейшем — между клиентским и relay-сервером.

**Транспорт:** приложение общается **исключительно** со своим клиентским сервером. Команды с ответами и события сервера идут по одному постоянному WebSocket (`wss`), байты файлов — отдельными HTTPS-запросами к тому же серверу; каждое соединение — TLS 1.3 и проверка `POST /auth` → `POST /auth2` (контракт §1). Доставка при убитом приложении — push, вопрос [Q2](../open-questions.md).

**Чем этот раздел отличается от соседних.** `../research/` изучает чужие решения и ничего не предписывает. Здесь — наш собственный контракт: то, что реализуют обе стороны. Открытые вопросы ведутся в [реестре](../open-questions.md).
