# Client-сервер

Всё, что относится к бэкендовой части NOX: **client-сервер** (принадлежит пользователю, разворачивается им самим), **relay-сервер** (компании), протокол между приложением и client-сервером, развёртывание, доставка уведомлений.

Client-сервер **реализован и работает**: Go + встроенная SQLite — код в `client_backend/`, контракт v0 в `protocol/contract-draft.md`. Устройство добавляется двумя путями: ссылкой с машины сервера — со служебной страницы или командой `noxd link` — или приглашением со спаренного устройства, которое срабатывает только после `Allow` на нём (фаза 046).

⚠️ **Ревизия модели 2026-09-10 (владелец, фаза 037).** Client-сервер принадлежит **одному человеку** и обслуживает только его собственные устройства; серверы разных людей между собой не соединяются. Всё, что между людьми, уходит на relay — и это делает **[Q13](open-questions.md) блокирующим**: без него продукт законченный, но однопользовательский. Решение [Q4](open-questions.md) переоткрыто и перерешено «сервер на пользователя», Q15 и Q17 сняты, заведены Q18–Q23. Фаза 034 (приглашение человека) отменена.

Открытыми остаются: протокол с relay (Q13), граница E2EE (Q1), push (Q2), ATS и App Review для личного сервера, канал которого идёт через собственный Rust-модуль приложения (Q14). Канал устроен по трекеру безопасности: TLS 1.3 с техническим сертификатом, кто на другом конце — решает проверка Eidolon на каждом соединении (фаза 044). Документы этого раздела фиксируют принятые решения и то, что осталось открытым.

## Соглашения раздела

- Документы **датируются** и не переписываются задним числом: устаревшее помечается устаревшим, а не молча правится.
- Утверждения опираются на первоисточники. **Непроверенное помечается непроверенным** и не переносится в выводы.
- Ресёрч без раздела о собственных ограничениях считается незавершённым.
- **Юридические разделы** — скоупинг-материал для постановки задачи юристу, никогда не замена юридической консультации.
- Решение, принятое в обсуждении, записывается **с датой и авторством**. Пересмотренное решение не удаляется, а помечается изменённым с причиной.
- Терминология: **client-сервер** (пользовательский) и **relay-сервер** (компании). В прозе строчными, в таблицах и на диаграммах с заглавной.
