# Документация NOX

**NOX** — кросс-платформенный мессенджер для iOS, Android, Windows, Linux и macOS (web — вне scope) на Flutter (Dart) с end-to-end шифрованием. Ориентир — Signal. Русское рабочее название в материалах — «Секюрный Мессенджер». Репозиторий — `nox-app`.

## Состояние

Приложение доведено до полноценного продукта на моках: смёржены фичи 001–021, все 17 экранов собраны, бизнес-логика настоящая (реактивные списки, unread, оптимистичная отправка, реальный файловый пикер, превью изображений, l10n EN+UK, персистентные настройки и сессия), данные живут в реальной локальной Sembast-БД и переживают перезапуск.

Бэкенд, транспортный протокол, криптоядро и модель синхронизации **намеренно ещё не выбраны**. Сетевой слой подготовлен, но инертен: интерфейсы `*RemoteDataSource` с подменой по `Environment`, конверт `ResponseEntity` + `EntityConverter`, `AppConfig.apiUrl` с auth-интерсептором и правилом `401 → forced logout`. Подробности рабочего режима — в конституции (`.specify/memory/constitution.md`) и `CLAUDE.md`.

## Соглашения

- Язык документации — русский.
- Код, идентификаторы, имена файлов, сообщения коммитов и названия веток — английский.
- Не смешиваем языки внутри одного артефакта: код остаётся английским даже когда упоминается в русском тексте, и наоборот.
- Имя продукта в UI и в прозе — **NOX** (все заглавные буквы).
