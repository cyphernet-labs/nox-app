# Документация NOX

**NOX** — кросс-платформенный мессенджер для iOS, Android, Windows, Linux и macOS (web — вне scope) на Flutter (Dart) с end-to-end шифрованием. Ориентир — Signal. Русское рабочее название в материалах — «Секюрный Мессенджер». Репозиторий — `nox-app`.

## Состояние

Проект на начальной стадии: формируются видение, требования и архитектура. Исходного кода пока нет — наполняется только эта папка `docs/`.

## Соглашения

- Язык документации — русский.
- Код, идентификаторы, имена файлов, сообщения коммитов и названия веток — английский.
- Не смешиваем языки внутри одного артефакта: код остаётся английским даже когда упоминается в русском тексте, и наоборот.
- Имя продукта в UI и в прозе — **NOX** (все заглавные буквы).
