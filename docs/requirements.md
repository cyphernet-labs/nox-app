# Функциональные требования

> Статус: черновик. Скелет создан на этапе инициализации проекта 2026-05-28. Документ описывает, **что** NOX должен делать; вопросы «как» (протокол, архитектура, хранилище) выносятся в отдельные документы.

Базовый ориентир — Signal. По умолчанию исходим из того, что аналог функции существует в Signal; в каждом разделе фиксируем отклонения и решения, специфичные для NOX.

Главное отклонение уже принято: клиентский сервер принадлежит одному человеку и обслуживает только его устройства, все чаты человека видны на всех его устройствах и больше нигде. Всё, что между разными людьми, пойдёт через релей, протокол которого ещё не существует ([Q13](client-backend/open-questions.md)), и в текущие рамки не входит. Принятая модель и границы итерации — [design/spec/overview.md](design/spec/overview.md).

## Сообщения

> TODO:
>
> - Чаты — решено: живут на клиентском сервере человека, прав и состава участников нет, чаты не удаляются. Диалоги 1:1 и групповые чаты с другими людьми — к релею (Q13).
> - Реакции, цитирование, ответы, упоминания.
> - Редактирование и удаление сообщений (только у себя / у всех).
> - Исчезающие сообщения (таймер на чат / на сообщение).
> - История: локальное хранение, поиск, экспорт.
> - Черновики.
> - Статусы — решено: только локальные `sent` / `pending` / `error`; доставки и прочтения нет — сообщение принимает собственный сервер человека, вопрос вернётся с релеем.
