## О продукте

NOX («Секюрный Мессенджер») — кросс-платформенный мессенджер для iOS, Android, Windows, Linux и macOS (web — вне scope) с акцентом на приватность и сквозное шифрование (end-to-end encryption, далее E2EE). Передаются текстовые сообщения и файлы (фото, видео, документы) по защищённому каналу.

Принятая модель: пространство NOX личное — клиентский сервер принадлежит одному человеку и обслуживает только его устройства, все чаты человека видны на всех его устройствах и больше нигде. Серверы разных людей между собой не соединяются; общение между людьми пойдёт через релей, протокол которого ещё не существует ([Q13](client-backend/open-questions.md)), и в текущие рамки не входит. Подробно — [design/spec/overview.md](design/spec/overview.md).

Концептуальный ориентир — [Signal](https://signal.org/). Это значит:

- E2EE по умолчанию для всех сообщений и файлов. Клиентский сервер — машина самого человека и хранит его переписку; где проходит граница сквозного шифрования — открытый вопрос [Q1](client-backend/open-questions.md).
- Минимизация метаданных на стороне сервера.
- Опенсорсный подход к криптографическому ядру (предположительно — подлежит подтверждению).

## Эталон и отличия от Signal

Базовый ориентир — Signal: модель UX, набор функций (1:1 и групповые чаты, голос/видео, исчезающие сообщения, верификация ключей).

От набора Signal принятая модель отступает: механика, завязанная на собеседника, — диалоги и группы с другими людьми, отметки о доставке и прочтении — ждёт релея (Q13); звонки в эту итерацию не входят ([overview.md, «Вне scope этапа»](design/spec/overview.md#вне-scope-этапа)).

> - Юрисдикция и инфраструктура.
> - UX и язык интерфейса.
> - Открытость / самохостинг / федерация — решено: у каждого человека свой клиентский сервер, серверы разных людей между собой не соединяются, между людьми — релей (Q13); кто размещает сервер — [Q5](client-backend/open-questions.md).
