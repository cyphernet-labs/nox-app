## О продукте

NOX («Секюрный Мессенджер») — кросс-платформенный мессенджер для iOS, Android, Windows, Linux и macOS (web — вне scope) с акцентом на приватность и сквозное шифрование (end-to-end encryption, далее E2EE). Передаются текстовые сообщения и файлы (фото, видео, документы) по защищённому каналу.

Концептуальный ориентир — [Signal](https://signal.org/). Это значит:

- E2EE по умолчанию для всех сообщений и файлов; сервер не имеет доступа к содержимому.
- Минимизация метаданных на стороне сервера.
- Опенсорсный подход к криптографическому ядру (предположительно — подлежит подтверждению).
